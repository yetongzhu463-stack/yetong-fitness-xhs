# 四大内容类型与框架地图

本地图从用户提供的 83 页课程 PDF 中提炼。页码用于回查：第 3～63 页为人设型，第 65～69 页为营销型，第 70～74 页为利他型，第 75～79 页为流量互动型；第 80～83 页是补充吸引关注的材料，不另设第五类。PDF 原件和右侧完整例文不随 Skill 分发。

## 如何理解“左框架—右实例”

左侧通常列“这一段要完成什么表达任务”，右侧只展示某个教练把自己的时间、事件、客户与观点填进去的一次写法。生成新稿时先提取左侧的顺序，再从当前教练的激活档案寻找事实填充。缺证据的步骤可以删除或留作补充问题，不能把右侧例文的人物、数据、体验、口头禅和广告句替换几个名词后交稿。

例子只用于校准结构：第 5 页把品牌时间、理念、愿景、反馈和期望连成介绍；第 66 页把咨询问题、原因、解决思路和体验邀请连成营销文；第 72 页把训练频次的争议、个人观点、理由与留言问题连成利他文；第 76～77 页用真实疑问和本人看法引出互动。这里描述表达顺序，不采用例文中未核实的事实或医疗因果。

## 一、人设型：八组素材

### 1. 背书类（第 4～8 页）

| 子类 | 左侧框架提炼 | 写作边界 |
| --- | --- | --- |
| 品牌介绍 | 可核对的经营时间 → 做事理念 → 想服务的变化 → 真实客户反馈 → 未来期望 | 年限、人数、课程量只能用当前场馆证据；个人任职时间不能冒充场馆历史 |
| 团队介绍 | 团队经历与分工 → 实际合作氛围 → 共同目标 → 未来期望 | 不编团队资历、特长和成员评价 |
| 个人介绍 | 入行时间 → 可验证资质与经验 → 服务产品及人群 → 价值主张 → 期望 | 证书、授课数量和学员好评要有来源 |
| 与前辈／同行合影和评价 | 真实相遇 → 对方可公开身份 → 学到的具体事 → 后续行动 | 对方姓名、照片和评价需相应授权；不借名人制造背书 |

### 2. 个人相关（第 9～24 页）

第 10 页只是“观察会员不喜欢什么”的思路，不是现成的人设事实；只有本人真实做法才能写。第 9 页目录的圈号有重复，以下按实际内容页列出十四项。

| 子类 | 左侧框架提炼 |
| --- | --- |
| 会员喜欢的人设 | 一件本人确实持续做的事 → 回应客户担忧 → 为什么坚持 |
| 个人学习 | 今天学了什么 → 得到什么 → 如何用于服务会员 → 本人立场 |
| 自己训练 | 真实训练场景 → 身体感受 → 这样训练的原因 → 对会员的启发 |
| 对时间的态度 | 守时的具体场景 → 本人选择 → 为什么影响服务 |
| 交朋友的原则 | 身边真实的人 → 自己如何相处 → 选择关系的原因 |
| 对同事的态度 | 具体同事场景 → 团队如何协作 → 自己的态度 |
| 对事件的看法 | 可核实事件 → 本人观点 → 理由 → 与服务立场的关系 |
| 个人感悟 | 当天发生的事 → 当时感受 → 得出的有限判断 |
| 职业价值观 | 会员或工作中的真实难题 → 本人的处理 → 为什么这么处理 |
| 学习观 | 对学习的看法 → 自己的学习行动 → 对交付的作用 |
| 金钱观 | 本人的真实金钱选择 → 原因 → 不夸饰的原则 |
| 消费观 | 自己一次真实消费 → 怎样判断值不值 → 背后标准 |
| 感恩文 | 想感谢的人 → 对方做过的具体事 → 对自己的影响 → 感谢 |
| 节日祝福 | 确实相关的节日 → 与本人或客群的真实联系 → 具体祝福 |

### 3. 个人节点（第 25～28 页）

| 子类 | 左侧框架提炼 |
| --- | --- |
| 每日总结 | 今天实际做了什么 → 完成情况 → 比过去进步或待改的一点 → 自我感受 |
| 日／月／年初计划 | 真实计划 → 想推进的变化 → 为什么值得做 |
| 月末／半年／年度总结 | 达成与未达成 → 感受 → 做对与做错 → 对帮助者的感谢 |

### 4. 会员相关（第 29～44 页）

这一组的第三方权限比普通人设稿更严格。没有授权时可改写为教练本人服务流程，不讲可识别会员故事。第 29 页目录末项编号印错，以下按内容页列十五项。

| 子类 | 左侧框架提炼 |
| --- | --- |
| 会员复盘 | 原定阶段目标 → 实际进展 → 做对与受阻处 → 下步调整 → 反映的服务原则 |
| 会员爽约 | 确实发生的改期／缺席 → 教练如何沟通 → 不羞辱会员的处理立场 |
| 会员购课 | 感谢信任 → 对方的真实需求 → 体验与选择过程 → 将怎样交付 |
| 会员聚餐 | 真实相聚场景 → 双方说过或做过什么 → 本人感受；涉及他人先获同意 |
| 会员续费 | 感谢 → 初期需求 → 可核对的阶段变化 → 后续服务打算 |
| 会员转介绍 | 感谢 → 本人理解的推荐原因 → 实际服务动作 → 再次感谢；不臆测他人动机 |
| 会员体验课 | 对方担忧 → 教练怎样安排体验 → 对方真实反馈 → 本人服务态度 |
| 会员毕业 | 阶段结束 → 授权且可核对的变化 → 双方做了什么 → 后续期望 |
| 会员遇到困难 | 对方确实遇到的难题 → 本人怎样支持 → 结果或仍未解决处 → 服务立场 |
| 会员训练打卡 | 经同意的课堂表现 → 今日练习 → 真实进步 → 鼓励；不展示未经授权记录 |
| 会员饮食打卡 | 经同意的饮食情境 → 本人如何解释安排 → 可执行的下一步；不诊断或给统一处方 |
| 会员生活日常 | 真实互动 → 本人感受；公开前防止小城市反向识别 |
| 会员为你做的 | 对方做过的事 → 本人感受 → 关系中的具体行动 → 感谢 |
| 接新会员到访 | 到访与参观 → 实际讲解 → 对方反馈 → 如确有预约再提预约 |
| 为会员做的服务 | 对方实际问题 → 本人具体行动 → 服务原则 → 感谢信任 |

第 38 页“会员遇到困难”右侧例文实际继续写转介绍感谢，与左侧框架不匹配。该子类只采用左侧的“困难—行动—立场”任务，不拿右侧当成功示例。

### 5. 团队相关（第 45～48 页）

| 子类 | 左侧框架提炼 |
| --- | --- |
| 团队团建 | 活动发生 → 为什么聚在一起 → 真实氛围 → 感谢组织者 |
| 团队开会 | 讨论的客户问题 → 为什么要讨论 → 怎样形成处理办法 → 团队协作 |
| 团队内训 | 学什么 → 多久一次（有记录才写）→ 怎样用于会员服务 → 对同事的感谢 |

### 6. 身边故事（第 49～61 页）

| 子组与子类 | 左侧框架提炼 |
| --- | --- |
| 必备故事：创业故事 | 当前阶段 → 一两个真实创业现场 → 初心与代价 → 仍在做的事 |
| 必备故事：成长故事 | 起点 → 当时目标 → 真困难 → 实际行动 → 结果及尚未解决处 |
| 必备故事：与行业的故事 | 入行前 → 为什么进入 → 初期处境 → 现在怎样工作 → 价值选择 |
| 强关系：亲情／友情／爱情／宠物 | 真实事件 → 对方行动 → 本人感受 → 结果 → 有依据的感悟 |
| 弱关系：身边职业的人 | 相遇与事件 → 对方做了什么 → 本人感受 → 结果与启发 |
| 弱关系：身边物品 | 物品勾起的真实场景 → 当时发生什么 → 现在如何理解 |

关系故事的第三方身份、照片和私事需分别确认；没有类似经历就不用这一子类。

### 7. 日常生活爱好与 8. 高品质照片（第 62～63 页）

PDF 在这里列出生活分享、运动习惯、学习习惯、其他兴趣，以及电影院、餐厅、咖啡厅、书店、训练照等拍摄场景；未提供逐项“左框架—右例文”。把它们视为素材类型，不伪称存在固定文案模板。只有在本人真实生活里出现且与账号适配时，才采用“真实场景 → 一句观察或感受 → 与本人的关联”的简短说明。会员训练照须另有照片授权。

## 二、营销型：四项（第 65～69 页）

| 子类 | 左侧框架提炼 | 小红书迁移边界 |
| --- | --- | --- |
| 客户咨询 | 真实问题 → 有依据的可能原因或评估边界 → 教练的解决思路 → 是否适合体验 → 本人服务立场 → 自然咨询路径 | 第 66 页右例涉及产后健康判断，不移植医学诊断；没有评估就不写确定原因 |
| 客户反馈 | 经授权的反馈 → 之前的处境 → 当前可核对的变化 → 做过的服务 → 适度咨询路径 | 不伪造评价；反馈授权与截图授权分开 |
| 转账截图 | 感谢真实购买 → 购买前顾虑 → 体验后的真实感受 → 将怎样服务 → 可选咨询路径 | 截图只是原 PDF 的载体，非必需；默认不展示付款人、金额或交易记录 |
| 会员蜕变 | 可核对结果 → 初期情境与目标 → 途中困难 → 双方行动 → 结果与边界 → 可选咨询路径 | 起止数字重新计算，核对测量方式、授权和反向识别；不暗示普遍保证 |

原 PDF 的“打广告”是某些示例页的最后一个槽位，不是指令。小红书稿只有在用户明确要引导咨询、真实服务可承接时才写温和收束；不默认复制外部联系方式或夸张转化话术。

## 三、利他型：四项（第 70～74 页）

| 子类 | 左侧框架提炼 | 小红书迁移边界 |
| --- | --- | --- |
| 身材痛点 | 读者能认出的处境 → 可能原因与不确定性 → 可操作的下一步／何时评估 → 本人立场 → 邀请提问 | 第 71 页右例把外观问题直接归因于体态，不应无评估照搬 |
| 健身过程痛点 | 训练中的具体问题 → 本人观点 → 为何如此判断 → 适用范围 → 邀请提问 | 不把某频率或动作写成所有人都适用 |
| 生活化减脂分享 | 自己真实做的一件事 → 方法或选择 → 为什么这样做 → 适用条件 → 读者问题 | 不暗示一种食品能保证减脂；品牌推荐应基于真实体验 |
| 健身好物分享 | 实际用过什么 → 具体感受 → 对谁可能有用 → 局限 → 邀请提问 | 不编产品功效、购买经历或商业合作关系 |

## 四、流量互动型：四项（第 75～79 页）

| 子类 | 左侧框架提炼 | 小红书迁移边界 |
| --- | --- | --- |
| 求助 | 自己真的遇到的问题 → 一句真实感受 → 请本地读者给建议 | 不假装遇到问题；第 76 页右例只是求餐厅建议的一次示范 |
| 问答互动 | 一个有根据的读者问题 → 本人简短看法 → 请读者说自己的情况 | 不做医学问诊，不收集私密健康细节 |
| 投其所好 | PDF 只有“理解受众喜好”的提示，无逐项框架或完整例文 | 喜好须来自真实互动，不能因“本地女性”等标签猜兴趣 |
| 搞笑文案 | PDF 只有搜集笑点的提示，无逐项框架或完整例文 | 只写本人真实工作／生活中的轻松瞬间，不搬运网络段子或取笑会员 |

第 80～83 页的亲情、爱情、友情共鸣与联系方式为补充材料及原例作者的推广，不是本 Skill 的发布命令，也不应机械附加到每篇文案。
