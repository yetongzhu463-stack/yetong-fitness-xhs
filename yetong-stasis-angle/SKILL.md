# yetong-stasis-angle：事件争点角度

把用户已选定的事件，转成对指定观众有意义、存在真实判断差异、证据能够影响结论的讲述角度。

## 先确定当前任务

- 用户要从一件事件找角度：执行下文。
- 只有抽象观点、产品介绍或泛选题需求：简短说明需要事件，只问一句“有没有一件已经发生的具体事件，可以作为起点？”然后停止。
- 用户要解释、逆向、检查或修改 Skill：按该任务处理；附带的事件材料不自动成为试跑指令。
- 用户只要完整稿件、批量标题或流量预测：说明本 Skill 交付的是事件争点与讲述方案，不擅自扩成其他任务。

## YETONG 接入与交接

本模块是 YETONG 内容线的事件选角阶段。分析已提供事件时无需人物 DNA，沿用本次明确的身份、受众与目标；未核验的用户经历仍标为用户自述，不据此补造档案事实。只有抽象观点时按上节问一个事件问题，不转成泛选题或强制建档；解释、检查或修改 Skill 的请求仍保持原任务。

完成后向主入口交接：事件与来源、用户身份及受众的来源、事实账本、候选评分与否决理由、主角度或“无合格角度”、缺口及表达边界。标题方向与开头 3 句属于讲述方案，不是已确认的本地发布标题或完整稿件，不强加服务地区。只有用户选定角度或明确授权代选，且已要求继续写稿，才由主入口按下游原有范围、本人 active DNA、地区与公开权限门槛交接。无合格角度时不进入成稿。

## 输入与最少提问

优先从当前对话提取：发生了什么；已有材料及其来源；用户与事件的关系；目标观众；希望观众理解或采取什么行动；已明确的平台和形式。

沿用用户已经给出的受众、身份和目标，不擅自替换。受众未给且不影响判断时，以直接受影响的人群暂定并标明，不因此停下。

仅在不知道发生了什么，或一个缺口可能使主要角度反转时，问一个最小问题并等待；其他缺口标注为用户自述、待核实或本轮推测后继续。不要求用户填完表单，不重复问已知信息。

## 共同边界

- 争点必须有不同判断、观众关切、可影响结论的证据和清楚的事实边界。
- 原文、转述、二创概括、玩梗、用户解释分开归属；不得在后续步骤把概括升级为当事人原话。
- 截图或链接存在，只能证明相应材料被提供；没有核对真实性与上下文时，不标成已独立核实。
- 不从单个经历推断整个行业；不把相关性写成因果，不擅自断言他人动机。
- 评价行为、观点、规则和可观察后果；不组织骚扰、挂人、隐私曝光或号召攻击。
- 关键前提变化时，同时更新事实账本、相关候选、评分和最终表达，不能只补一条备注。

## Step 1：建立事实账本

用简表列出材料、来源、确定程度、能支持什么和表达限制。

| 类别 | 判断与允许表达 |
|---|---|
| 已核实事实 | 已核对相应原文或记录及必要上下文；可以在该范围内陈述 |
| 用户自述 | 用户报告的经历，尚未外部核实；用第一人称或明确说明来源 |
| 合理推断 | 有材料支持但仍有其他解释；写明推断及其成立条件 |
| 未知 | 缺失过程、未经核实的动机或因果；列为缺口，不作为事实 |

来源可以用“材料 A”“用户自述”等标记；没有来源的细节不补造。将待核实命题列出来，不以“待核实”标签为无证据指控背书。

依据：证据归属与核查的操作规范；四类账本是本 Skill 的设计，不冒称某理论的原有分类。

## Step 2：扫描四类争点

| 类别 | 检查问题 |
|---|---|
| 事实 | 到底发生了什么？哪项事实、过程或因果尚有争议？ |
| 定义 | 同一行为应当归入什么概念？分类标准差在哪里？ |
| 价值 | 根据什么标准判断它合理、重要、可批评或可原谅？ |
| 行动 | 面对该事件或同类情况，谁应当怎样处理？有哪些选择？ |

每类生成 0—2 个候选。没有材料支撑可以为空，不为了凑齐四类虚构争议。

依据：Stasis；“行动”是面向内容实践的扩展，不等同于古典程序／管辖问题的全部原义。

## Step 3：把候选写成可争论的问题

每个候选保留以下字段，可合并成紧凑表格：

```text
争点问题：
立场 A：
立场 B：
观众为什么在意：
用户独有的位置：
已有证据：
缺失证据：
```

逐项检查：

1. A 与 B 是否在同一主体、条件和判断标准下产生不同结论或行动？“有帮助”与“还需要其他条件”可以同时成立，不能直接伪装成互相反对。
2. 双方是材料中实际出现的判断，还是本轮构造的待检验判断？后者明确标注，不能声称已有两派或大量支持者。
3. 每条证据支持哪项主张？还需要什么论证桥梁？什么反例或条件变化会削弱它？不能只摆材料而不检查推论。

无判断差异的候选不成立。可以澄清争议究竟落在适用范围、充分条件、优先级或评价标准上；仍不能形成分歧时删除。

依据：Stasis 确定分歧；Toulmin 检查材料、主张和推论边界。

## Step 4：组织讲述框架

将候选压成一条命题，再组织为：

```text
事件事实 → 值得讨论的公共问题 → 两种判断的实际差异 → 基于证据且有限定的立场 → 观众可使用的判断或行动
```

检查究竟将什么定义为问题、原因是否有证据、采用什么评价标准、希望观众带走什么。缺少原因证据时可以保留问题，不强行指定责任或动机。

优先选择用户有讲述位置、能连接同类处境或公共规则的角度。只靠炫耀被关注、情绪宣泄或臆测动机成立的命题降级或删除。

依据：Entman 框架理论；组织材料不能替代证明事实与因果。

## Step 5：评分、否决与选择

评分是编辑判断，不是调查数据或流量预测。每项给 0、1、2 分，并用现有材料解释关键得分。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 公共相关 | 只与当事人有关 | 一小类人会遇到 | 连接较广的处境、规则或身份 |
| 冲突清晰 | 没有不同判断 | 分歧尚需收窄，或仅为待检验判断 | 两种判断清楚，且有材料证明双方实际存在 |
| 证据支撑 | 关键主张依赖猜测 | 有部分证据，结论必须收窄 | 关键主张有证据，必要上下文完整 |
| 个人独特 | 缺乏用户讲述位置 | 用户有相关经历 | 用户亲历或有独有材料，能增加理解 |
| 内容收益 | 只有情绪宣泄 | 能增加认识或谈资 | 能帮助观众作判断、行动或理解长期问题 |

风险分：

- `0`：事实边界清楚，评价针对行为、观点或公共问题。
- `-1`：存在待核实材料，收窄主张后仍可讨论。
- `-2`：候选依赖动机臆测、人格指控、隐私曝光或号召攻击。

总分 = 五项得分之和 + 风险分。

先执行硬性否决：无真实判断差异、证据支撑为 `0` 或风险为 `-2`，均不能成为主角度；高总分不能抵消。再检查扣分后总分是否至少为 `6`。

合格候选同分时，优先证据支撑，再比较观众相关与用户讲述位置，并用一句话说明取舍；不假装能精确预测效果。

候选可按证据收窄一次并重新评分，或转成有依据的第一人称经验与公共问题。仍不合格就交付缺口和取证方向；不能通过改写隐藏同一项无证据指控，也不能循环凑主角度。

依据：新闻价值辅助判断观众关切，Toulmin 检查论证；分数、阈值和排序是本 Skill 的操作规则。

## Step 6：交付主角度与备选

有合格候选时，只保留 1 个主角度和最多 2 个备选；没有备选可以留空。按顺序交付：

1. 事实账本。
2. 争点候选：保留成立依据、双方差异、受众与材料缺口。
3. 评分与淘汰理由：五项分、风险分、扣分后总分及否决项。
4. 主角度。
5. 最多 2 个备选。
6. 取证与表达边界。

主角度使用：

```markdown
一句话命题：
争点类型：事实／定义／价值／行动
观众为什么会进入：
这个角度为什么适合你讲：
可以确认地说：
暂时不能说：
需要补的证据：

讲述路径：
1. 事件事实开场；
2. 抛出争点；
3. 呈现两种判断的实际差异；
4. 给出证据、推论和有限定的立场；
5. 回到观众可使用的判断或行动。

标题方向：
开头 3 句：
```

备选只写一句话命题、适合条件和淘汰风险。不交完整稿件或批量标题。

没有合格候选时，以“当前没有合格主角度”结束筛选，给出关键淘汰理由、最少需补证据和可收窄方向，不填出假的主角度、标题与开头。

简单事件可压缩表格，但不能省去事实与推断的区别、核心分歧、主张边界和不能说的内容。

## 完成与停止

- 正常完成：用户得到有证据边界的命题、实际分歧、选择依据、讲述路径和开头。
- 缺口完成：没有合格角度时，用户知道缺什么、能收窄到哪里。
- 澄清等待：只问影响继续的最小问题，不先编出依赖未知答案的主角度。
- 直接讲事实、分歧、证据与风险；不把情绪激烈等同于观点成立，不使用空洞二元反转句式，不承诺热搜、爆款或平台推荐。
- 中文与英文、数字之间合理留空，使用规范中文标点。理论解释或来源问题出现时，再读 [理论与来源](references/theory-map.md)。
