# 叶童3：4封面

## 这项 Skill 解决什么

这不是把标题贴到一张好看的海报上。它把文章里读者真正需要核对的承诺，变成封面上可一眼理解的**可见证据**：例如“课够不够 60 分钟”必须成为“单节 60 分钟”这样的标签，而不能只画一个“1”。

交付始终包含：

1. **封面信息地图**：标题、读者要判断的事、承诺、证据载体、人物动作、底部保障语一一对应；
2. **构图方案**：3:4 构图、层级、色彩、留白和人物与载体的前后关系；
3. **可执行中文生图提示词**：可交给图像模型生成画面底图；
4. **准确叠字清单**：把所有必须 100% 正确的中文交给后期叠字，而非把正确性赌在模型手里；
5. 用户明确要求“直接生成”时，再生成、检视并只修正没有通过的部分。

## 适用边界

适用：已有标题、正文、口播稿或至少 3 条已确认事实；且内容是本地线下健身教练的课程标准、服务交付、流程、对比、提醒、器械或场馆相关主题。

不适用：

- 只有“帮我想个爆款标题”而没有内容事实；先要求用户给出正文或已确认观点。
- 写完整文章、虚构客户案例、医疗/减脂疗效承诺、没有证据的“全城最好”等；不在封面中编造或强化此类主张。
- 没有照片却要求“和我本人长得一模一样”的直接生成；先请用户上传正面参考图。没有参考图时，可以只输出用 `[图1：本人照片]` 占位的方案和提示词。

## 输入与事实规则

优先沿用本轮已给信息，不重复询问。缺信息时一次只问**最影响真实性或成片**的一项：

1. 没有具体内容：问“请发标题和正文，或至少列出 3 条你愿意对外承担的事实。”
2. 要本人封面却没有图 1：问“请上传一张本人正面、清晰、无遮挡的参考图。”
3. 有地域、价格、时长、免费、资格或效果承诺但来源不清：问用户确认准确措辞；不要自行补全、搜索后当作门店事实，或承诺必然减重。
4. 标题是否固定不明确：默认保留用户原题；只可把地域放进辅助小字，且地域必须来自用户明确提供的公开服务范围。

将“本节免费”“60 分钟”“不玩手机”等当作用户要发布的事实，不把它们改写成更夸张的保证。涉及不满意、退款或免费，仅使用用户确认的原意与范围。

## 工作流

### 1. 先建信息地图，禁止先挑风格

读完内容后，先读取 [信息地图规则](references/information-map.md)，在脑中完成下表。信息不完整时，只为补全关键事实提问；否则直接提出方案。

| 字段 | 要回答的问题 |
|---|---|
| 读者任务 | 看完封面，读者要判断/核对什么？ |
| 主标题 | 最短、最有张力、且不超出原文的结论是什么？ |
| 证据载体 | 哪个实体能承载这些承诺：训练计划板、对比卡、流程条、器械记录、教学场景？ |
| 证据标签 | 每一条对应什么可读的事实、数量或动作？ |
| 人物动作 | 人如何与载体发生关系，而不是站在旁边摆拍？ |
| 辅助信息 | 地域、身份、保障语分别放在哪里；哪些必须叠字？ |
| 事实来源 | 该信息来自用户正文、用户确认还是不应写？ |

**硬规则：**标准/流程类封面中的每个编号后都必须跟一条具体、短、可核对的标签；3–5 条为常规上限。只有编号、不写标准，视为信息地图不合格。

### 2. 用内容选择证据载体

读取 [版式路由](references/layout-routes.md)。按内容选路线，而非按“看起来酷”选路线：

- 课程标准、服务承诺、报课前核对项 → **训练计划板/核对板**；
- 明确的前后差异、两种选择 → **双卡对比**；
- 已确认的服务流程、上课步骤 → **流程条/训练记录**；
- 场馆、器械、真实教学动作是重点 → **教学实景/器械记录**。

若文章同时包含多种内容，只保留一个主载体。不要在一张 3:4 封面中堆叠卡片墙、二维码、长段解释和无关图标。

### 3. 定人物、层级与视觉语言

读取 [视觉语言](references/visual-language.md)。用户要求本人封面时，人物必须使用用户提供的图 1；保留可识别五官和年龄感，不把真人替换成陌生模特。未提供图 1 时，方案只能标注 `[图1：本人照片]` 占位，或在用户明确不要人物时改为信息载体主视觉；不能臆造具体真人。人物、标题、证据载体应发生遮挡，形成“人正在展示/核对证据”的关系。

标题是第一层；证据载体与其标签是第二层；地域/身份/保障语是第三层。所有关键信息距画面边缘至少约 10%，避开头部、手、脸和平台裁切风险。

### 4. 先分清“底图文字”与“最终文字”

读取 [质量闸门](references/quality-gates.md)。图像模型可以在底图中尝试生成短标签以营造真实感，但模型生成的任何中文都**不能自动视为最终稿**。

输出时固定给两套文字：

- `画面内短标签`：供图像生成理解结构，仍须在成片复核；
- `后期准确叠字`：逐字、逐标点列出最终文字、颜色、位置、层级。这个清单是交付的一部分。

若用户要求直接生成，先生成底图，再检查。中文有错字、漏字、模糊、被裁切，或事实被改写时，必须重做/后期叠字；不得把“模型偶尔会错字”当作完成。

### 5. 输出方案与提示词

没有要求直接生成时，按以下顺序交付，措辞简洁：

1. **封面方向**：一句话说清读者看见什么、为什么可信；
2. **信息地图**：用精简表格列出标题、载体、标签、人物动作、保障语；
3. **3:4 中文生图提示词**：第一句必须是“3:4 竖版构图。”；准确引用主标题和画面内短标签；明确人物、动作、前后遮挡、色彩、背景、光线和禁止项；
4. **后期准确叠字清单**：主标题、辅助小字、每条标签、保障语各自的精确文字、位置、字号层级、颜色；
5. **自检结果**：逐项列出事实、文字、构图三个维度是否通过；未通过则指出需要用户确认的唯一项。

提示词不得用“高级感”“很好看”“适量”等空词代替可执行描述。标题必须逐字放在中文引号内；不得悄悄改数字、地域、门店名或保障范围。

### 固定输出模板

除非用户只问一个非常窄的问题，否则使用以下标题；不省略“准确叠字清单”和“自检结果”：

```markdown
## 封面方向
[一句话：读者看见的证据和应得出的判断]

## 封面信息地图
| 主标题 | 读者任务 | 主载体 | 人物动作 | 保障语 |
|---|---|---|---|---|
| ... |

证据标签：
1. ...
2. ...

## 中文生图提示词
3:4 竖版构图。...

## 后期准确叠字清单
| 文本 | 精确文字 | 位置 | 样式 |
|---|---|---|---|
| ... |

## 质量自检
- 事实：通过/待确认（具体原因）
- 文字：通过/待后期叠字（具体文字）
- 构图：通过/待调整（具体元素）
```

若用户仅说“直接生成”，在生成前仍可先简短展示“主标题 + 证据标签 + 保障语”的硬事实复述，避免把未确认承诺写进画面。

### 6. 只在明确授权后直接生成

用户明确说“直接生成/出图/做一张”且已给合适的人像/资产时，才进入出图。生成前重述一次将被写进画面的硬事实；生成后按 [质量闸门](references/quality-gates.md) 检视。

优先修复唯一的失效层：

- 人脸不像/手势不对 → 只重做人物与姿态；
- 标签干燥或抽象 → 只补充具体事实标签与版面密度；
- 文字错误 → 保留正确画面，进行准确叠字或文字定向编辑；
- 画面拥挤 → 删减非关键小元素，而不是缩小所有字。

连续两次未能得到准确中文时，停止反复抽卡式重生，交付干净底图加完整叠字清单，并明确说明这是保证发布文字准确的路径。

## 完成标准

仅在以下条件全部满足时称为“可发布”或“完成”：

- 主标题没有夸大、与用户确认内容一致；
- 每项重要承诺有可见、可读、具体的证据标签，而非纯编号；
- 图 1 的人物身份一致，动作与证据载体有真实互动；
- 3:4、关键信息 10% 安全边距、移动端缩小后仍有主次；
- 所有最终中文、数字、门店/地域、保障语均由逐字质检通过；
- 未通过项已修改，或清楚标注为需要用户确认/后期叠字，绝不伪称完成。
