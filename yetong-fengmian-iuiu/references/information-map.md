# 封面信息地图规则

## 核心原则

封面不是正文摘要。它只回答一个读者问题，并让这个判断有一个可看见的依据。

`读者任务 → 可发布承诺 → 可见证据 → 人物动作 → 文字层级`

“好看但没有依据”的装饰，不计入证据；“有五个序号”也不等于“读者知道五条是什么”。

## 提取方法

1. 从正文找读者将要判断的一个决定：报不报名、怎么核对、两种做法差在哪、一个流程是否可靠。
2. 只摘 3–5 个能对外承担的事实。五条以上时，选最可行动的 3–5 条；原文明确就是“五条”时，可以保留五条，但每条必须更短。
3. 每条改写为“对象 + 可核对事实/动作”，不扩大原意。
4. 将这些事实放进一个真实存在的证据载体，而不是把它们漂浮成装饰小卡片。
5. 把“为什么是这个人说”安排成人物正在指出、举起、书写、核对该载体的动作。

## 标签到证据的改写

| 原文中的抽象说法 | 合格的可读标签 | 不合格做法 |
|---|---|---|
| 课够不够六十分钟 | `单节 60 分钟` | 只写 `1` 或 `时长有保障` |
| 上课别玩手机 | `上课不玩手机` | `专注服务` |
| 要记录训练计划 | `每节记录计划` | `专业指导` |
| 一对一要盯练 | `全程看动作` | `认真负责` |
| 不满意当节免费 | `不满意 当节免费` | `售后无忧` |

标签遵循：一条一个意思、优先量化/动作、尽可能 4–9 个汉字（数字和单位另计）、不使用无法核验的形容词。若必须保留法律或业务限制，使用用户确认的简短版本，不私自删改。

## 信息地图模板

| 层级 | 内容 | 来源/验证 |
|---|---|---|
| 主结论 | `[固定标题或经确认的主标题]` | 用户标题/正文 |
| 读者任务 | `读者要当场核对什么？` | 正文的核心决定 |
| 主证据载体 | `训练计划板 / 对比卡 / 流程条 / 器械记录` | 内容类型 |
| 证据标签 | `序号 + 具体事实`（3–5 条） | 用户正文逐条对应 |
| 人物动作 | `举起、指向、翻看、书写、示范` | 图 1 和载体可实现 |
| 辅助锚点 | `地域/人群/身份` | 用户明确提供 |
| 保障语 | `范围明确的后果或行动提示` | 用户确认的政策 |
| 不写内容 | `无来源效果、绝对化、私密客户数据` | 风险拦截 |

## 反例判断

- 题目是“报课前问五条”，画面只放教练肖像和“五条”大字：**不合格**，读者看不见五条。
- 画面放五张漂亮卡片，但文字是“专业、负责、有效、安心、靠谱”：**不合格**，是形容词不是证据。
- 画面放训练计划板，写“单节 60 分钟、上课不玩手机、每节记录计划、全程看动作、不满意当节免费”：**合格**，内容、载体、行动可互相验证。
