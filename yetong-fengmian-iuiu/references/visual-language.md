# 视觉语言与提示词构造

## 层级

一张封面只应有三个阅读层级：

1. **第一眼**：主标题，最大、最短、最强对比；
2. **第二眼**：证据载体及其 3–5 个具体标签；
3. **第三眼**：地域、人群、身份、保障语等辅助锚点。

主标题可在人物背后被头部或计划板轻微遮挡，不能遮脸或使关键字不可读。正文不是封面文案；不要将整段解释塞进图里。

## 人物规则

- 只把用户明确提供的人像称为图 1，并在提示词中写明“参考图 1，保持五官、发型、年龄感和肤色一致”；
- 人物动作必须服务于证据：举板、指向、勾选、翻看、示范，不能双手摆拍却没有说明关系；
- 上半身/半身通常更适合 3:4 文字封面；人物面积约 35–55%，给标题和载体留空间；
- 不美白换脸、不过度磨皮、不增加手指，手与标签接触处要自然；
- 没有图 1 时，不承诺人物一致性，也不臆造具体真人身份。

## 色彩选择

| 内容气质 | 推荐 | 禁止 |
|---|---|---|
| 标准、核对、避坑 | 深藏青/墨黑底 + 亮黄色证据标签 + 白标题 | 霓虹描边、数据粒子、无意义科技光 |
| 过程、记录、陪练 | 暖白/石墨灰 + 深蓝/橙色小锚点 | 满屏贴纸、卡通仪表盘 |
| 对比、选择 | 同一背景上的明暗双区 + 一种高对比强调色 | 将“错误方”做成人身贬低或恐吓 |
| 场馆、动作 | 真实场馆主色 + 可读中性色标题 | 虚构可识别门店标识、过度商业渲染 |

色彩是为了区分“标题、证据、背景”，不是为了制造花哨。每张图只保留一组强调色。

## 中文生图提示词骨架

提示词第一句固定为：`3:4 竖版构图。`

之后按此顺序写，必要时删除不适用部分：

1. `参考图 1 的人物身份要求`；
2. `人物位置、表情、视线、手势`；
3. `证据载体的尺寸、位置、材质、标签结构及具体文字`；
4. `主标题、辅助文字与遮挡关系`；
5. `背景、配色、光线、小元素`；
6. `安全边距、可读性、禁止项`。

示例结构（用实际信息替换中括号）：

> 3:4 竖版构图。参考图 1 的男性五官、发型、年龄感保持一致，只取半身……右手举一张竖向深色训练计划板，板上整齐标记“1 单节 60 分钟”“2 上课不玩手机”……巨大的中文标题“[主标题]”位于人物背后……所有人物脸部、标题、计划板和标签距四边至少约 10% 边距……不要霓虹发光、数据流、粒子特效、错别字、乱码、额外人物。

模型内的中文只用来表达版面意图；发布用文字仍以后期准确叠字清单为准。
