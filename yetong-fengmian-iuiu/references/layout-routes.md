# 版式路由

先根据正文内容选择一个主载体，再决定配色；不要先挑“黑黄”“高级”“杂志感”。所有路线均为 3:4 竖版，关键元素保留约 10% 安全边距。

## A. 训练计划板：标准、核对项、承诺

适合：几条上课标准、报名前问题、服务交付清单、保障机制。

- 人物在画面下半部或右下，直视镜头；一手举竖向深色计划板，另一手指向关键一条；
- 计划板约占画面 28–38%，边缘使用高对比描边；
- 标签按 1–5 垂直对齐，每条包含编号和具体事实；
- 主标题在人物后方形成遮挡，不压脸；保障语放画面底部小标签；
- 深藏青/墨黑底加亮黄色，用于“检查、标准、风险提醒”类内容；不要霓虹、数据流、粒子。

## B. 双卡对比：两种做法/前后差异

适合：同一问题的错误与正确、两种选课方式、明显可证实的前后差别。

- 用左右或上下两块大卡，不超过两类；
- 左侧写“只问价格”等旧做法，右侧写“先看交付”等正确做法；每侧最多 2–3 个事实；
- 人物位于中间/下部，手势引导读者从左到右；
- 比较对象必须来自正文，不能制作体型羞辱、虚假瘦身效果或未经同意的客户照片。

## C. 流程条/训练记录：方法、步骤、执行感

适合：预约到上课的流程、训练计划如何记录、一次课怎么进行。

- 以一张可见的训练记录页、时间轴或三段流程为主；
- 人物可拿笔勾选或翻开记录，强调“真的在执行”；
- 只保留 3–4 个步骤，每步是动作或产物，如“体测记录 → 当节计划 → 动作盯练”；
- 避免做成仪表盘、满屏数据或软件界面。

## D. 教学实景/器械记录：场馆和动作才是证据

适合：器械使用、现场教学、场馆环境、单个动作重点。

- 使用用户提供的场馆/器械素材；没有就不伪造可识别门店或设备；
- 人物示范或纠正一个动作，旁边仅留一个短的记录牌或动作要点；
- 标题留在上方干净区域，场景本身当作证据；
- 不把无关的价格、五张标签和多个产品同时堆进场景。

## 选择优先级

若正文里有多种信息，依下列优先级选一个：

1. 读者需要核对承诺 → A；
2. 读者需要二选一判断 → B；
3. 读者需要理解过程/记录 → C；
4. 读者需要确认现场/动作 → D。

无法归类或正文没有可承担事实时，停在信息地图阶段，索取事实而不是生成泛化封面。
