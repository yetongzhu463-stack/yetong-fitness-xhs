# 质量闸门与修订规则

## 发布前逐项检查

### P0：任何一项失败都不可称为完成

- [ ] 是 3:4 竖版；标题、脸、手、证据载体和底部保障语未越过约 10% 安全边距。
- [ ] 人物若声明为图 1，本人五官、年龄感、发型未被替换；没有多余人物、畸形手指或不可能姿势。
- [ ] 主标题、地域/门店、人群、数字、时长、免费/退款/保障范围逐字与用户确认内容一致。
- [ ] 每一条重要承诺都有具体标签；没有“专业、可靠、有效”等空泛标签充数。
- [ ] 任何模型生成中文已经逐字核验；错字、漏字、乱码、被遮挡或太小的文字，已通过定向修改或后期叠字修正。
- [ ] 不含无来源疗效、绝对化效果、虚构客户、虚构场馆或未获确认的业务政策。

### P1：读得懂才算有效

- [ ] 缩小到手机封面预览时，先看见主标题，其次看见证据载体，最后才看见辅助信息。
- [ ] 载体是一个整体，人物正举起、指向、翻看或示范它；不是人物和五张漂浮卡片的拼贴。
- [ ] 有且只有一个主载体；图标不超过 2 个，且确实解释内容。
- [ ] 人物、标题和载体存在前后遮挡，但脸、关键字和标签均不被遮住。

### P2：最后打磨

- [ ] 标准/核对类内容使用高对比，但无霓虹、数据流、粒子特效和廉价光效。
- [ ] 标签间距整齐，编号、短句与强调色一致。
- [ ] 底部保障语不是主标题的重复，并已标明适用范围。

## 后期准确叠字清单模板

| 文本层 | 精确文字 | 位置 | 样式 | 检查点 |
|---|---|---|---|---|
| 主标题 | `“[主标题]”` | 上部/人物后方 | 超粗中文黑体，白色；强调词可用强调色底 | 不压脸、不改字 |
| 辅助锚点 | `[地域/人群]` | 主标题下方 | 小一号白字 | 来源已确认 |
| 标签 1–5 | `[序号] [具体事实]` | 证据板内等距排列 | 高对比、同一规格 | 每条对应正文 |
| 保障语 | `[确认过的短语]` | 底部标签 | 强调色底/深字 | 范围不被扩写 |

## 修订优先级

一次只处理一个失效层，并保留已通过内容：

1. 事实/文字错误 → 改文字或准确叠字；
2. 人脸/姿态/互动错误 → 只改人物与手势；
3. 标签缺少具体信息 → 改信息地图和载体内容；
4. 阅读顺序混乱 → 改尺寸、位置、删小元素；
5. 仅在 P0 与 P1 通过后，才调整质感、光线和装饰。

若连续两次文字仍不准确：保留画面正确的无字/弱字底图，改用后期叠字。目标是发布正确，不是反复赌模型的中文能力。
