# 构图模板

只读取并使用用户已选择的构图。所有模板同时遵守 `visual-language.md`。

## 1. 产品冲镜头风

适合开箱、相机、手柄、麦克风、数码配件、体验和玩法指南。

```text
3:4竖版小红书封面。参考图1保持人物一致性，参考图2保持产品外观与结构一致。

采用近距离广角镜头。人物位于画面中央或中央偏后，占画面约50%，呈现[确认的表情]；人物一只手将产品伸向镜头，产品位于前景中央或前景偏右，占画面约40%，产生明显但自然的前大后小透视，另一只手做[确认的手势]。手指数量与握持关系自然，产品Logo、按钮、镜头和端口清晰准确。

背景为[确认的背景]，轻微虚化和降对比，光线方向与人物一致。顶部为[顶部标题]预留大字区域，底部为[底部主标题]预留超大字区域；人物脸部和产品关键结构不被文字遮挡。加入0-2条靠近产品功能点的短手写标注和细箭头。

真实科技博主实拍质感，自然肤质，清晰产品材质，纯白粗黑体主标题，单个关键词使用暖橙黄 #F5A623，深灰柔和投影，高对比但不过度锐化。
```

## 2. 人物手持讲解风

适合快捷键、设置方法、使用技巧、软件教程和产品功能说明。

```text
3:4竖版小红书封面。参考图1保持人物一致性，参考图2保持产品或设备一致性。

人物位于画面[左侧/右侧]，占画面约55%，半身出镜，身体略朝向产品，表情自信亲切。人物一只手在胸前稳稳托住产品，另一只手指向产品屏幕、按键或标题区域。产品占画面约30%-40%，角度清楚，关键结构无遮挡。

画面另一侧或顶部放置[顶部标题]，底部或空白侧放置[底部主标题]。围绕产品加入1-3条倾斜的短手写说明与细箭头，例如[辅助标注]。背景为[确认的背景]，保持简洁并轻微虚化。

真实教程封面，人物和产品双主角，纯白粗黑体搭配一个暖橙黄 #F5A623 关键词，深灰柔和投影，不使用清单、贴纸墙或漫画描边。
```

## 3. 单人口播教学风

适合“一个人拍摄”“高效口播”“剪辑收音”“经验公开”等内容。

```text
3:4竖版小红书封面。参考图1保持人物一致性。

人物居中，占画面约60%，胸像或半身面对镜头，呈现[确认的表情和动作]。如果有参考图2，将麦克风、电脑或拍摄设备放在人物手中或桌面前景，保持真实尺度；没有素材时只生成通用、无品牌的设备。

背景为真实[室内/桌面/工作区]，柔和中性光或暖光，略微虚化。顶部放置大标题“[顶部标题]”，底部放置最大标题“[底部主标题]”。人物两侧可加入不超过3条手写说明和极简图标，例如[辅助标注1]、[辅助标注2]，但中心区域保持干净。

像真实自拍视频经过专业封面排版，纯白超粗黑体、深灰柔和投影，最多一个暖橙黄 #F5A623 关键词，表情自然，不使用综艺贴纸和高密度装饰。
```

## 4. 多画面对比风

适合改造前后、三项设置、多个机位、不同方案和工作流展示。

```text
3:4竖版小红书封面。参考图1保持主人物一致性，参考图2、图3作为对比或步骤素材。

主人物位于画面中央偏下，占画面约50%，半身出镜，双手指向上方两个画面或一手指向标题。人物表情自信、友好并带轻微发现感。

画面上方并排放置2张圆角画面卡片，分别使用参考图2和图3，卡片有轻微投影，尺寸一致，中间使用一枚简洁箭头表示变化关系。卡片可以被人物头部轻微遮挡形成层次，但不能遮住关键信息。

顶部小标题为“[顶部标题]”，底部放置超大主标题“[底部主标题]”，底部标题可占画面高度约25%。背景为[暖灰/米色/确认的背景]，干净统一。除箭头外不加入多余贴纸。

真实科技教程对比封面，纯白粗黑体、深灰柔和投影，暖橙黄 #F5A623 仅用于箭头或一个关键词，人物和对比素材清晰。
```

## 5. 主题场景故事风

适合户外体验、天文摄影、旅行测试、真实使用故事和强概念产品内容。

```text
3:4竖版小红书封面。参考图1保持人物一致性，参考图2保持产品一致性。

人物位于画面[左下/右下/中央]，占画面约45%-55%，以[确认的动作]展示产品。产品位于前景或人物手边，占画面约30%-45%，与人物视线和手势形成明确联系。

背景为与主题相关的[太空星云/蓝天树木/城市夜景/真实场景]，场景有氛围但细节不过密，人物光线、色温和阴影与环境一致。顶部以轻微弧形或两行排布标题“[顶部标题]”，底部或人物侧边放置“[底部主标题]”。加入1-2个手写问号、细箭头或短说明强化故事点。

真实人物与主题场景融合，避免廉价抠图感；纯白粗黑体为主，根据背景使用暖橙黄 #F5A623 强调一个关键词，标题清楚，人物脸部与产品无遮挡。
```

## 标题拆分建议

- 产品名或场景作为顶部引题，内容收益作为底部主标题。
- 顶部示例结构：`一个人在家`、`OSMO NANO`、`六个快捷技巧`。
- 底部示例结构：`高效拍口播`、`玩法指南`、`爆款封面`。
- 示例只说明结构，不能直接套用与用户内容无关的文案。
