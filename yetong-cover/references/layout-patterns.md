# 本地健身封面构图模式

只读取并使用与本篇内容和可用素材匹配的一个小节。以下是构图方法，不是可以冒充真实场馆或会员成果的现成照片。所有模式遵守 [封面方法与素材门槛](cover-method.md)。

## 1. 本人动作教学

适合“第一次练会不会跟不上”“这个动作我怎么教”等利他内容。主体是**真实教练本人**演示正文确实会讲的动作，人物和关键关节无遮挡；旁边留一处主标题空间。若尚未确认演示哪个动作，不指定深蹲、硬拉或器械；先给留位与拍摄要求。没有本人影像时只交实拍清单和空镜框架，不生成其面孔。

## 2. 服务过程与信任

适合课前沟通、训练计划、课后反馈、课程标准等营销或利他内容。可拍本人翻开空白训练计划、在真实场馆示范沟通、指向不含会员信息的流程板。画面里只能出现档案确认真实提供的服务动作；不生成聊天截图、合同、评分、价格或承诺作为假证据。标题突出会员最关心的一个问题。

## 3. 本地到店场景

适合通勤、时间安排、场馆介绍。使用已授权的真实门店入口或场内照片、教练本人和可核对的商圈信息；本地线索是识别辅助，不应盖过具体问题。未提供场馆实拍时可交拍摄机位与文字排版，不生成“本店实拍”假图；未核实到店时长不写“十分钟就到”。

## 4. 教练经历与立场

适合人设型内容。本人真实工作照片或获准公开的经历物件为主，文字只写此篇正文会解释的选择、转折或立场。不要复刻另一位教练的职业故事，不用通用“逆袭前后对比”冒充本人过去。无本人照片时用真实可补拍的环境/物件清单，不伪造旧照片。

## 5. 问题对照与互动

适合两个真实选择、常见顾虑或讨论型内容。可用同一教练的两幅姿势/两个真实场景并列，辅以简洁问句；不是会员减脂前后对比。两边必须是正文确实比较的选项，不把假“最差”“必选”当结论。无法证明差异时用问题型构图，不做带结论的视觉暗示。

## 共通输出骨架

```text
比例：3:4 竖版；主体和标题在安全区内。
画面：只描述已获准公开的本人/场馆/器械；未知项写“待拍/待确认”，不用想象补全。
光线：以真实拍摄条件为准，保持自然肤质和动作可见。
无字底图提示：只指定人物位置、场景、留白、画幅及禁止伪造的元素，不生成文字。
叠字清单：短句、引题/主句、放置区域、层级、已确认的地名；视觉效果以可读为准。
核对：真人/会员肖像权限、标题与正文兑现、场馆及数据真实性。
```
