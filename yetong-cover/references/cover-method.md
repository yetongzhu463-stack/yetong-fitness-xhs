# 封面方法与素材门槛

仅在进入封面设计阶段时读取。本方法服务教练所在地的线下潜在会员，人物与产品资料来自该教练自己的已激活档案，不存在“全体教练共用叶童视觉身份”。

## 一句话任务卡

```text
本人档案身份与核验状态：
本地客群与到店范围：
已选题/正文的具体问题与可兑现的回答：
主内容类型：人设型/营销型/利他型/流量互动型
已确认可公开的地点、服务动作、称呼和品牌视觉：
本次可用的真实照片/视频帧/截图及各自授权：
不能展示和仍需核对的内容：
本轮只要方案/要无字底图提示词/明确要成品图片：
当前 Agent 是否有可用生图与叠字/编辑能力：
上轮已交付的提示词及用户选择（若为接续任务）：
```

## 先判断是否能做正式封面

| 情况 | 动作 |
| --- | --- |
| 选题或正文尚不具体 | 回到选题；若只有一个标题，先问正文到底回答什么。 |
| 标题/正文含未经证实的“保证瘦多少”“练几次必有效”等结果，或虚构优惠 | 停止正式封面；交标题或文案环节修正，不通过“辟谣标签很小、承诺字很大”的版式绕过。 |
| 无本人照片，但要以本人出镜 | 给拍摄清单、取景框和叠字方案；不虚构其面孔，也不输出照片级“本人”底图提示。若用户明确要直接生图，先请其提供可使用的本人照片。 |
| 无会员素材授权 | 不展示会员本人、身材、聊天、数据或“匿名但可识别”的细节；改用教练本人动作、空场服务流程或通用示意。 |
| 无场馆照片或地址证据 | 不把生成的场馆、Logo、地标写成真实门店；给场景拍摄清单或非照片级的构图留位示意，不写具体无法核实的到店信息。 |
| 有照片但公开权限不清 | 先问该素材是否获此用途授权；档案 active 不替代照片/肖像许可。 |

## 内容类型影响画面，不机械套模板

| 主类 | 优先展示 | 不做 |
| --- | --- | --- |
| 人设型 | 教练本人真实工作、可公开的经历物件或当下场景 | 虚构成长节点、资质、家人或会员合影。 |
| 营销型 | 可核对的服务过程、到店路径、真实场馆片段 | 伪造咨询截图、付款记录、会员评价、课程承诺。 |
| 利他型 | 本人动作演示、具体判断步骤或训练常见问题 | 未经确认的动作处方、医疗结论、效果保证。 |
| 流量互动型 | 一个真实、本地人能讨论的问题或两种情境 | 与正文无关的对立、猎奇、冲突或性别刻板印象。 |

## 视觉与文案约束

- 默认 3:4 竖版；核心人、物、文字留足裁切安全区。主标题短而易读；若原题较长，可在不改变意思的前提下拆成引题与主句，准确全文仍保留在笔记标题/正文中。
- 一张封面通常只有一个主视觉和一个主信息；辅助标注 0–2 条，必须解释画面或实际内容。不要强制每张都用“上大字＋下大字”、大广角或同一种手势。
- 用本人现有视觉资产的颜色和字体优先；没有时给“可替换的中性示例”，如白字＋深色柔和投影＋一处暖色强调。不能把示例色称为所有人的品牌色。
- 可以用 AI 做背景清理、构图参考或无身份指向的示意；不得改变会员身体、伪造结果证据，或让不存在的器械/空间看起来是这家店实拍。
- 文字清单与生图提示词分开；默认无字底图，再在 Canva、醒图等后期工具准确叠字。若直接生图含中文，仍逐字检查标题、数字、地名和 Logo。
- 真实产品/器械的型号、场馆 Logo、课程价格、开放时间、人物外貌、地标和数据都只来自已确认且获准公开的来源。不凭行业常识补细节。

## 缺口优先级

先解决会让封面误导或侵犯他人的缺口：标题事实/效果承诺 → 人物与会员素材授权 → 本人照片/真实场景 → 美观偏好。美观偏好通常可以由任务卡推断并标为可替换，不必形成多轮问卷。

## 从提示词到成图的接力

“无字底图提示词”仅用于生成画面；把它单独粘贴到生图工具，得到的通常不是含准确标题的完整封面。要在当前窗口完成成图，另给一段可直接执行的**完整封面成图指令**，包含：3:4 画幅、使用哪些已获授权的参考照片、主体与留白位置、经核对的封面短句及逐字准确要求、字号层级、不可添加的虚假元素，以及中文无法准确渲染时的“先出无字底图，再准确叠字”退路。人物或真实场馆不能只凭文字描述生成；同窗口工具若不能接收参考图，就停在拍摄/排版方案。提示词不应含私人档案的绝对路径或无关个人信息。

可复用的成图指令骨架（只供组装；交付用户前替换或删去全部方括号占位项，不把“待确认”写进可执行提示词）：

```text
使用本轮已确认可用于此封面的本人／场馆参考照片〔逐项列素材，不补造〕，制作 3:4 竖版小红书封面。
画面：〔这篇正文能兑现的一项真实动作或服务场景〕；主体位于〔位置〕，在〔位置〕保留标题安全区。
封面文字：主句“〔已核对原句〕”；辅助字“〔如确有必要且已核对〕”。逐字核对汉字、数字、地名，不加额外承诺。
视觉：〔已确认的品牌色，或标为可替换的中性配色〕；手机缩略图可读，人物肤质与动作自然。
禁止：编造教练长相、门店设施、会员身材变化、客户评价、证书、Logo、优惠或效果保证。
若当前生图工具无法准确生成中文，请先输出无字底图，并使用可用编辑/排版能力按上述文字清单叠字；无法完成叠字时如实标为底图而非可发布成品。
```

跨窗口复制这段指令时，也须把其中提到的有权使用参考图片一并提供给目标 Agent；仅复制文字，不能让另一窗口知道教练本人或门店的真实外观。

输出完整指令后，只有当前 Agent 确有生图能力、必要参考素材可传入且授权已核对时，才询问“直接生成”或“继续优化提示词”。“直接生成”只授权本轮生成，不自动允许公开素材或发布笔记。回复“继续优化提示词”则依据反馈更新本篇方案，不擅自生成图片。用户一开始就明确要成图且条件齐全时可直接执行，无需重复征求同一动作的同意。生成结果必须再检查文字和事实；有错误时修复或标为未完成草稿。
