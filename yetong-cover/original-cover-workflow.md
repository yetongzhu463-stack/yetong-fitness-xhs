# 叶童的小红书爆款封面

把用户提供的文章、选题、产品资料和参考图，转化为统一的真人实拍科技风小红书封面方案。默认产出可直接用于图片生成模型的提示词，以及用于后期准确叠字的排版清单。

## 交互原则

- 一次只问一个问题，等待回答后再继续。
- 用户已经提供的信息直接记录并跳过对应问题。
- 除粘贴内容和上传图片外，所有封面决策都使用编号选择题。
- 不逐次询问字体和标题效果；这些属于固定品牌规范。
- 如果用户给出明确标题，原样使用，不擅自改写。
- 只套用用户最终选择的构图模板，不输出所有模板。
- 不复刻参考博主的脸、身份、文案或某一张作品；只使用抽象的构图语言，并以用户自己的参考图和素材创作。

## 信息收集流程

### 0. 内容

如果用户尚未提供主题，只问：

请发送这张封面的文章、选题、产品信息或视频内容概要。

### 1. 构图

让用户选择一种：

1. **产品冲镜头风** — 产品或手部成为巨大前景，适合开箱、体验和玩法指南
2. **人物手持讲解风** — 人物手持产品并指向重点，适合技巧、功能和快捷操作
3. **单人口播教学风** — 真人面对镜头，顶部和底部双标题，适合拍摄、剪辑和经验教程
4. **多画面对比风** — 主人物配合2-3张圆角小画面，适合前后对比、设置改造和工作流
5. **主题场景故事风** — 人物、产品融入太空、户外或主题环境，适合体验故事和强概念选题
6. **根据内容推荐** — 由模型选择最匹配的构图，并用一句话说明理由

### 2. 人物参考图

只问：

请上传图1人物参考图。建议提供1-3张同一人物的清晰正脸或半身照，以保持人物一致性。

收到后只记录为人物参考，不追问外貌描述。如果用户明确不露脸，允许使用手部、背影、侧脸或局部出镜，但仍需参考图。

### 3. 产品与辅助素材

让用户选择：

1. **有产品实拍图** — 图2起为产品照片，优先保持外观、接口和Logo准确
2. **有界面或截图** — 图2起为软件界面、教程结果或操作画面
3. **有前后对比素材** — 图2、图3分别是改造前后或不同方案
4. **有多种素材** — 同时包含产品、截图或场景图
5. **没有额外素材** — 根据主题生成通用物件，不虚构具体品牌细节

用户选择1-4后，只要求按顺序上传图2、图3等。精确产品是选题核心时，没有产品参考图就不能凭空补造按钮、镜头、端口或Logo；简短说明这一限制并继续使用通用化产品表现。

### 4. 人物动作与镜头

让用户选择：

1. **产品伸向镜头** — 广角透视，产品最大，冲击力最强
2. **手持产品讲解** — 产品位于胸前，另一只手指向产品或标题
3. **对镜口播** — 手持麦克风或自然讲解，画面真实亲切
4. **双手指向标题** — 人物居中，用手势串联顶部和底部标题
5. **轻松展示或点赞** — 适合推荐、体验和使用心得
6. **根据内容决定**

### 5. 背景

让用户选择：

1. **真实室内** — 浅灰、米色或暖色房间，轻微虚化
2. **简洁品牌纯色** — 橄榄绿、暖灰或与产品互补的纯色
3. **户外自然环境** — 蓝天、树木、城市或真实使用场景
4. **主题化场景** — 太空、摄影棚、工作台等与内容有关的环境
5. **沿用参考素材背景**
6. **根据内容决定**

### 6. 标题

如果用户没有给出标题，根据内容生成3个候选，只让用户选编号：

1. **候选标题A**
2. **候选标题B**
3. **候选标题C**
4. **重新生成3个标题**

标题规则：

- 核心主标题4-10个字，优先口语化、结果导向和低理解成本。
- 可以拆成顶部引题与底部主标题，但底部主标题必须最醒目。
- 教程突出“玩法”“设置”“上手”“高效”“指南”等明确收益。
- 产品内容突出产品名或品类，但不编造未提供的型号和结论。
- 避免空泛词汇、长句、夸张承诺和与正文不符的数字。

## 生成前读取

收集完成后：

1. 读取 [references/visual-language.md](references/visual-language.md)，应用固定品牌视觉语言。
2. 读取 [references/layout-templates.md](references/layout-templates.md)，只使用已选构图对应的模板。

## 最终输出

按以下顺序输出，不再提出新问题：

1. **方案摘要** — 构图、动作、背景和标题各一行。
2. **完整生图提示词** — 明确参考图编号、人物位置、产品透视、前中后景、背景、光线、标题留位和3:4比例。
3. **文字排版清单** — 精确列出顶部文字、底部文字、辅助标注、颜色、位置和层级，便于在Canva、醒图或Photoshop中准确叠字。
4. **生成约束** — 保持人物与产品一致性、手指自然、产品结构准确、文字不遮挡五官和产品关键部位。

默认将文字写进生图提示词，同时提供排版清单。若用户明确要求无字底图，生图提示词中只保留文字安全区和排版留位，准确文案仍放入排版清单。

如果用户明确要求直接生成最终图片，先完成上述确认，再使用可用的图片生成能力制作3:4封面；保留排版清单以便核对中文文字。
