# 本地健身教练小红书封面

把一篇已确定的本地会员内容转成**这位教练自己能拍、能证明、能公开**的 3:4 小红书封面方案。默认交付一套方案、实拍清单和准确叠字清单；有可使用的实拍素材时再给无字底图提示词，并在满足条件时给可供生图工具执行的完整封面指令。文字提示词不能替代本人或场馆参考照片。只有用户明确要求最终图片且素材条件满足时才调用当前 Agent 可用的图像生成能力。保留真人实拍、清晰主标题、少量标注等通用视觉原则，不把叶童个人的长相、场馆、配色或科技产品风格作为所有教练的默认值。

具体判断见 [封面方法与素材门槛](references/cover-method.md)；只读取最终选中的 [构图模式](references/layout-patterns.md)。

## 进入条件与最少追问

1. 用户须提供这位教练自己的 `person-dna.md` 路径，或由本次会话主入口明确交接。只读取该路径，不扫描私人目录。先从**本 Skill 所在目录**运行 `python3 scripts/check_profile.py <person-dna.md>`，或使用脚本的绝对路径；通过只表示档案已激活，逐条事实和图片授权仍要核对。身份不符时先确认使用哪位教练。
2. 须有一个**具体的本地会员选题或现成正文**，足以说清“给谁看、这篇回答什么、正文实际能兑现什么”。只有“做个减脂封面”等宽泛方向，回到选题；只有一个吸睛标题却不知道正文内容时，只问“这篇实际会讲哪件事”，不凭标题编造画面和效果。
3. 已选标题可沿用，但“原样使用”不等于认可其事实。若含未经证实的减重数字、保证效果、虚构优惠或暗示医疗结论，**停止正式封面制作**，指出具体风险并交给标题/内容修改环节；不能把危险句子做成最大字，也不能擅自把原稿改成“辟谣”来绕过风险。
4. 由档案与当前选题推断内容类型、客群、城市和服务场景；已有信息不重问。默认推荐一种最适合的构图。只有缺少会改变结果的关键事实或素材使用许可时问一个合并问题，不要求用户依次选择构图、动作、背景、颜色和字体。

档案路径未交接时只问路径。档案不存在、无效或不是 `active` 时，不生成带有该教练城市、经历、场馆、会员或口吻的个性化封面，原样提示：

> 人物 DNA 尚未激活。当前只能调用通用方法，无法启用个性化选题、真实经历映射与个人表达校准。完成「人物底色访谈」并确认档案后，才能解锁完整的叶童内容方法引擎。

仅用户明确要求跳过访谈时，才可给不含个人事实的“通用版式思路”；不暗示这就是其真实门店或本人形象，也不代为激活档案。

## 工作顺序

1. **固定内容承诺。** 记录本地目标人群、具体顾虑、正文真正提供的解答/过程，以及人设型、营销型、利他型或流量互动型主类。封面文字可以比笔记标题更短，但不得引入正文没有的承诺；只有封面设计请求时不代替标题 Skill 重写发布标题。
2. **做素材账。** 区分教练本人照片、场馆/器械实拍、会员照片或聊天/数据、授权证明、无身份指向的通用素材。逐张核对来源、是否属于这位教练、是否同意此用途、可公开范围和是否需再次确认。人物 DNA 的 `active` 不自动授权任何照片、Logo、会员结果或第三方肖像。无本人参考照时给拍摄清单或纯场景/手部版式，不生成陌生脸冒充本人；无真实场馆照时不生成“这就是本店”的假场景。会员身体、前后对比和截图若缺单独授权，不使用；即使有授权，也不生成或篡改身体变化。
3. **选一个模式。** 依据 [封面方法与素材门槛](references/cover-method.md) 选与这一篇相符的构图，再读取 [构图模式](references/layout-patterns.md) 中对应的小节。以真实教练、训练动作、上课过程或可核对的到店场景为主体；不为“爆款感”虚构训练结果、证书、门店设施、城市地标或会员反馈。
4. **校准视觉承诺。** 文字在手机上易读，主体、标题、少量标注层级清楚；地点只在已确认且有助于本地读者识别时出现。配色使用已确认的场馆/个人视觉规范；没有规范时采用中性可替换配色，不能宣称为该教练品牌色。人物动作应与正文/实拍能兑现的教学内容一致，不替教练决定未提供的专业动作细节。
5. **按请求交付。** 默认先给可拍的方案和文字清单。若没有可用的本人或真实场馆实拍，只给拍摄清单、留位示意和叠字方案；不写会生成“本店实拍”的照片级提示词。已有可用素材时，区分**无字底图提示词**与**完整封面成图指令**：前者只生成背景/画面，不能称为可直接发布的封面；后者须写入经核对的封面文字、位置、参考图使用方式及禁止伪造事项。若生成工具不能可靠处理中文文字，先生成无字底图，再通过可用的编辑/排版能力准确叠字；不能实现时只交底图和叠字清单，不谎称成品。具体提示词格式见 [封面方法与素材门槛](references/cover-method.md)。
6. **提示词后的选择。** 给出可供当前窗口生图的完整封面指令、且已核对必要素材/授权和工具可用时，在回答末尾明确问一次：**“要我按这版提示词直接生成封面吗？回复「直接生成」；想先调整画面或文案，回复「继续优化提示词」。”** 这一步只征求生成动作，不等于获得素材公开、发布或伪造事实的许可。若用户本轮已经明确要求直接成图且条件齐全，不重复追问，直接生成。若只给无字底图提示词、缺关键素材或当前 Agent 无生图能力，不提供做不到的“直接生成”选项；说明缺口或建议把提示词和有权使用的参考素材带到支持生图的窗口。
7. **处理选择。** 用户在同一封面任务下回复「直接生成」视为本次生成授权：重新核对提示词、素材与授权仍有效，向可用生图工具传入真实参考图，生成并检查人物/场馆真实性、标题逐字准确、数字地名和画幅。发现错字、变形或虚构证据时，能安全修正则继续编辑，否则明确标为未完成草稿，不说“可直接发布”。用户回复「继续优化提示词」时，依据其反馈修改；若方向不明，只问最影响画面的一个问题，不调用生图工具。每次给出新的可执行完整提示词后仍按第 6 步提供选择。没有生图工具时绝不声称已生成图片。

## 输出

通常只给**一个首推方案**：①本篇承诺与选用模式；②画面和实拍清单（谁、哪里、做什么、哪些素材可用）；③有合格实拍时的无字底图提示词，以及条件满足时可用于当前窗口的完整封面成图指令；或缺素材时的拍摄说明与留位示意；④准确叠字清单（封面短句、位置、层级）；⑤待核对的事实/肖像/公开许可；⑥符合第 6 步条件时的“直接生成／继续优化提示词”选择。用户明确要求多个方案时才提供确有不同视觉理由的少量备选，不列一长串模板。

若必须停止，说明卡在具体哪条事实、标题或素材授权，以及现在能做什么；不得输出看似可直接发布的高风险封面。不承诺播放、点击、咨询或成交。用户未要求安装、发布或修改 Skill 时，本模块不执行这些动作。
