# 本次产品资料与证据卡

人物 DNA 说明“谁在什么城市为哪些会员服务”；本卡说明“这次到底推广哪一门课”。它们互相校对，但不把每次课程构思变成重新建档，也不擅自改写人物档案。

## 产品阶段

- **草案／设计中**：用户正在构思，交付、规则尚未确认。可梳理内部优势假设、候选客群、证据采集和条件排期；不能给消费者一篇把它写成已开售、已交付、已有结果的成稿。下一步只确认会改变营销的产品事实。
- **已确认／可交付**：用户确认产品真实存在、描述及服务做得到。可按已确认范围写课程介绍、标准和适配说明；并不意味着已经售出或已经有反馈。
- **已有体验／交易素材**：在可交付基础上有特定记录。逐项核实课程归属、发生日期与公开权限；没有记录的部分仍视为没有，不是一个阶段标签自动解锁全部客户框架。
- **暂停／失效**：课程停开、规则过期或原授权撤销时，保留历史信息供内部复盘，不继续写当前招募或沿用失效权益。重新推广先确认当前交付与许可，只更新相关字段。

只给名称、想法或“打算推”不视为已确认；用户说明实际课次、动作、权益并确认能交付，可以据此判定，不必反复索取一句仪式性的口令。名称带“极速”或“康复”不证明相应效果或资格。

## 最少补充问题

先复用上下文和本人档案；缺口合并成一轮，允许一起语音回答。资料足够写一条时不要为整套方案的可选素材阻止当前输出。可这样问：

> 把这门课按真实情况说给我听，口语就行：叫什么、实际怎么上（内容、课次、时长、形式），现在是构思还是已经能交付？最想让哪些本地会员来了解，主要回应哪个问题？跟普通上课相比有哪些做得到的标准或服务？这次想先让人了解、预约还是报名？如果要写完整活动，再告诉我周期和已定的价格／规则；如果有可公开的咨询、反馈、效果、报名或复购记录，一并给我，没有也可以，我们先用课程事实写。

不要向用户重问档案已确认的城市和身份。若需本次课程范围而档案只有整个场馆客群，可只问新课程适配。不把未提价格、截止日、优惠、人数标成必须补齐，除非用户希望写含这些信息的销售稿。

**资料未知不等于事实不存在或未定。** 本轮未提供价格／时段，就在内部卡标“未提供、本轮不使用”，消费者文案直接省略；不能替用户宣布“价格还没定”“时段尚未确定”。没给课后服务资料不等于没有课后服务；只有用户明确否定或说未定，才可据此写。缺少素材与实际没有某事件也要区分：前者不能推断“还没有人上过”。

## 卡的记录字段

本卡是工作记录格式，不要求用户填表。不把空字段塞进成稿，也不把假设和事实混在同一行。

| 字段 | 记录和判断 |
| --- | --- |
| product_id／名称 | 当前课程唯一简称和用户原名；相似课程分开 |
| 阶段、来源、核对时间 | 草案／已确认，以及明确的用户事实来源；不猜开售日期 |
| 本地提供者与范围 | 当前教练、真实场馆、城市／服务半径；不虚构分店或跨城服务 |
| 交付 | 实际内容、课次、每次时长、周期／形式；缺可选项就省略，不添加课程成分 |
| 适配／不适配 | DNA 中主力人群及本产品条件；新客群是策划假设而非已验证客源 |
| 表面目标／深层顾虑 | 目标是想实现什么；顾虑是为何犹豫／难坚持；保留已提供原话 |
| 优势与标准 | 场馆、本人、当前产品各自的事实 → 一项动作 → 帮助；通用场馆承诺不自动扩成所有新课权益 |
| 价格与权益 | 仅记录已确认并适用于本产品的版本；退款／补偿规则不得放大或自动照抄其他课程 |
| 目标行动 | 已存在的了解、咨询、预约或购买路径；不是强行加抢购和限时 |
| 周期／频率 | 用户指定优先；否则明确示例假设；每天条数不等于效果承诺 |
| 可用素材清单 | evidence_id、类型、所涉 product_id、日期、事实、授权范围、脱敏要求、已具备／待核对／未具备 |
| 待确认与禁止 | 当前不能写什么；只询问本轮必需的事实或权限 |

## 素材授权与框架资格

- **真实咨询**：有问题与实际回应，可公开问题情境才进入 M01；私密健康经历不用原样披露。
- **文字反馈**：忠实引用或转述，只写记录覆盖的体验；所涉课必须一致。文字授权和截图授权分开；不把“感觉舒服”变成减脂数据或康复证明。
- **身材变化**：本课程个案、时间范围、测量口径、数值及教练具体动作都须可核对。旧课程案例标明旧课；不同周期照片不得冒充一节课效果。数据和照片分别核权利。
- **新购／复购**：有真实支付或成交记录并核产品归属、日期；“购买过其他课程后买新品”不自动等于“本课程复购”。公开具体个案或截图需相应许可，匿名也要考虑本地识别风险。未允许金额时不展示金额。
- **预约**：有实际预约即可使用 F05，但不是成交或结果；排队、售罄、剩余名额另需真实数量、时间口径。
- **本人过程／打卡**：真实学习、备课、训练、课堂标准；缺当天行动就不用“今天刚”“每天都”。只计划实施的标准保留为计划。

每次接续计划检查新增素材和规则变化。证据只够说“一位”就不写“大家”，同一会员重复引用不统计为新增案例；获准公开一次不自动等于无限复用。所有内部卡和会员原素材保留在用户授权的私人位置或当前会话，不存进 Skill 目录，不自动上传 GitHub。不把本轮新增产品未经确认写成人物档案的永久事实。
