# 朋友圈推广框架与自动匹配

把课程事实、教练本人的 DNA 与真实素材填进结构，不套用示例的课程、客户、品牌、句子或效果。以下 ID 用于排期和逐条推荐，便于检查“这条为什么这样写”。

## 一、五张教学图片只提取五种结构

| 结构 ID | 可读表达任务 | 抽象顺序 | 不带入的内容 |
| --- | --- | --- | --- |
| I1 | 产品硬广 | 定义产品 → 具体目标／问题 → 内容或服务介绍 | 原课程名称、身体审美标准、图片人物与对比结果 |
| I2 | 产品效果／价值 | 具体问题或价值 → 有证据的个案过程／变化 → 服务判断与适用条件 | 未核实健康判断、教练审美决定效果等因果保证 |
| I3 | 产品科普 | 常见误区／疑问 → 有限解释 → 实际方法或标准 → 适用场景 | 未核实医学因果、效果倍数、优惠金额及活动期限 |
| I4 | 产品口碑 | 授权客户评价 → 实际交付细节 → 教练回应或服务立场 | 图片原作者评价与夸赞；不能写成当前客户说过的话 |
| I5 | 产品热销 | 真实报名／复购／预约事实 → 服务安排 → 温和咨询 | 原例预约热度、身体对比、排队；该图并非收款截图证据 |

I2 只描述结构，不要求每条价值介绍都有客户。没有本课程个案时删除个案步骤，采用真实课程标准与产品事实；不能补写成功客户。

## 二、三个分类层各负其责

1. **推广板块 P1～P4**：这条承担哪一个推广任务，定义见 [marketing-method.md](marketing-method.md)。
2. **原包四大主内容类型**：人设型、营销型、利他型、流量互动型。每条选一个主类型；纯介绍课程也可归“营销型／课程介绍”，不必冒充原 PDF 中存在第五个营销子类。
3. **原包营销型四子类 M01～M04**：客户咨询、客户反馈、转账截图、会员蜕变。只在真实事件与权限满足时选用；没有事件，用 F01／F02／F03，不写“今天有人问我”或“会员都说”。

来源框架沿用原包四大内容类型地图的“左侧任务顺序”逻辑；本文件已提炼本任务需要的结构，不复制完整实例，不要求安装其他文案模块、DBS 或读取原 PDF。

## 三、通用课程写法

| 框架 ID | 写法与触发证据 | 默认板块／主类型／来源结构 |
| --- | --- | --- |
| F01 | **课程介绍**：课程是什么 → 优先人群与具体目标 → 实际包含什么 → 适配／不适配边界 → 已存在的了解或预约路径。需要已确认产品事实。 | P1／营销型／I1 |
| F02 | **价值与标准**：本地客群的一个真实困扰 → 课程如何安排 → 一项具体标准及其作用 → 适用场景 → 温和咨询。学习／研发可加入本人真实过程；没有案例不用案例槽位。 | P2／营销型；重在本人学习可选人设型／I2 |
| F03 | **有界科普**：一个产品相关问题或误区 → 有依据且有限的解释 → 实际课程做法或选择标准 → 谁适合先了解／评估 → 邀请提问。不需要捏造客户提问，不能诊断或承诺疗效。 | P2／利他型／I3 |
| F04 | **授权口碑**：经授权的评价原话或忠实转述 → 对应的真实服务细节 → 本人回应／服务立场 → 可选咨询路径。不能放大评价或把自己想说的话装进客户嘴里。 | P3／营销型／I4；事实完整时可进一步匹配 M02 |
| F05 | **真实预约与服务安排**：实际预约事实及时间口径 → 将怎样安排课程或服务 → 感谢／温和咨询。有预约即可，不需要收款；不等于已经购买或取得效果。 | P4／营销型／I5 |

## 四、原包营销型四种写法

| 框架 ID | 原子类与必要证据 | 写作顺序 | 自动匹配 |
| --- | --- | --- | --- |
| M01 | **客户咨询**：确实发生的客户问题、本人回应；可公开的问题情境 | 问题原话／忠实转述 → 有依据的可能原因或评估边界 → 教练解决思路 → 产品适配判断 → 实际服务立场 → 自然咨询 | 主 P2、主营销型；解释误区用 I3，价值／标准用 I2 |
| M02 | **客户反馈**：真实反馈、所涉课程、文字公开授权；截图另有授权 | 授权反馈 → 之前处境 → 当前可核对感受／变化 → 做过的服务 → 适度咨询 | 主 P3、主营销型、I4；如果只是服务满意，不添身材变化 |
| M03 | **转账截图**：真实新购或复购事实、产品归属；披露截图另有授权 | 感谢真实购买 → 有记录才写购买前顾虑／体验感受 → 将怎样服务 → 可选咨询 | 主 P4、主营销型、I5；标新购或复购；截图不是必须，默认不展示付款人、金额、交易号等 |
| M04 | **会员蜕变**：本课程真实案例、起止时间／测量口径／变化、本人实际动作、相应公开授权 | 可核对结果 → 初期目标和处境 → 途中真实困难 → 双方动作 → 结果及个体边界 → 可选咨询 | 主 P3、主营销型、I2；前后数字重新计算，不保证别人获得同样变化 |

原包人设型的“个人学习、自己训练、每日总结、为会员做的服务”，适合 A2／A5 的真实过程内容。原包利他型的“健身过程痛点”，适合 F03。流量互动型只在用户确有互动需求时用真实问题或适配讨论，不为了凑四大类型假装求助，也不在朋友圈公开征集私密健康信息。

## 五、自动选择步骤

1. 确认本条想让读者理解产品、相信标准、看到体验，还是了解真实选择；先选主 P。
2. 查看本条可用证据。真实咨询选 M01；授权反馈选 M02；真实购买选 M03；已核对的本课程变化选 M04。多种证据并存时按本条主目的选一个主框架，其他只做辅助，不机械拼接全流程。
3. 没有上述客户事件：介绍产品选 F01、解释标准／适用场景选 F02、回应课程相关问题选 F03。只有预约选 F05。拥有授权口碑但缺完整变化过程选 F04，不强补 M02 中的变化。
4. 根据表达重心标一个主内容类型，并记录 I 结构来源。F 和 M 是写法选择，不是新造的第五大内容类型。
5. 从当前教练 DNA 取本篇需要的城市、客群顾虑、实际优势、交付动作与表达习惯；从本次产品取课程事实。每个事实保留来源，案例和图片分别核公开权限。
6. 先按任务顺序写，缺事实的可选步骤直接删除；必需事实缺失则换适用框架或标待补，不能补造连接句。最后检查是否像本人、是否说清课程以及下一步是否可执行。

## 六、每条推荐与文案的交付卡

推荐卡标注：**主推广板块、主内容类型、框架 ID、图片结构 ID、受众／顾虑、目的、核心事实及来源、素材状态、下一步行动**。排期中可缩为字段或短句，不要求每条搬出全份 DNA。

用户要成稿时，推荐卡后给一条可直接编辑的朋友圈文案：开头只承担一个吸引或说明任务，中段围绕一项具体服务／事实展开，结尾可邀请了解适配情况。用户给定名称与已确认规则照用；优惠、名额、截止时间、价格、退款与赠课承诺只写当前产品已确认的版本。

禁写检查：原教学图片的案例冒充用户事实；匿名但可反向识别会员；伪造评价／收款／预约；无记录的“今天又”“每天排满”；将一般体验写成治疗或长期改变；同一案例改装成每日新增结果；以炫富、羞辱身体或夸张保证制造焦虑。
