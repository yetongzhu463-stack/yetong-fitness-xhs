# 来源与改编

叶童写作感 0.1.0，技术标识为 yetong-xiezuo-huoren。

基于 [KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing) 的 1.2.0 安装包改编。上游 MIT 许可和版权声明完整保留在 [LICENSE](../LICENSE)。

沿用并调整上游通用散文、现实、虚构与文体参考；主入口、任务材料判断、分级审稿和检查脚本按新方案重写。词法检测的部分词表、模式和统计思路来自上游 check_prose.py，不代表其作者认可本改编。

主要变化：短篇按本轮任务判断材料；新增输入与成稿的事实增量对照；正常纠正和标点按语境判断；规则统一维护；工具增加文体、字数目标与 JSON 报告。事实核对仍需模型与必要研究，不能由脚本证明。

修辞情境、合作原则、QUD 与读者预期是本项目分析和设计时的理论对应，不冒充上游作者的具名引用。材料预算和分级检查是待验证工程方法。

验证材料与实际结果记录在 evals。它们不作为日常写作的示范答案，也默认不公开分发。没有实际完成的验证不宣称通过。
