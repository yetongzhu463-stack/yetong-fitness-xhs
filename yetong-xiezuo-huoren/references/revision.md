# 分级审稿

初稿完成后读取。先保护已经成立的原句与声音，再修复错误。检查只服务当前作品，不把每条提醒都变成改写任务。

## 第一层：必须修复

### 对照事实与作者意图

逐项对照输入和成稿的重要现实陈述。

- 行动是否扩大，例如看过变试过、讨论变决定、截图变成功付款。
- 数字、日期、身份、报价、具体症状、疾病、对白、心理和动机是否新增。
- 用户自述、公开事实、发布方自述、旁人回忆与作者推断是否混在一起。
- 先后或相关是否被写成原因，个案是否被写成全部，反问是否暗含了未经支持的事实。
- 作者原本的立场、情绪或结论是否被偷换。收窄断言不等于消灭判断。
- 标题、开头、图片说明与结尾是否也遵守同样边界。

重要新增公开事实没有依据就核实或删除，不能给虚构细节伪造来源。模型对照不能替代必要的外部核验；脚本也不能判断真假。

### 对照本轮任务

文体、读者、篇幅和改写幅度是否正确。用户要求轻改时，是否不必要地重排全稿；只要一段感受时，是否擅加教程、推广或评论区引导。

用户明确指定禁词、标点、格式或精确长度时作为本轮硬性条件检查。约字数使用约定容差，不为凑字数改变事实。

## 第二层：检查每段是否往前走

给每段指出其新事实、动作、区别、问题、后果或必要情绪。若只能说“又强调了一次”，合并或删掉。

不要把同一建议拆成重要性、必要性、好处、代价四段。删掉一段，信息、判断和情绪没有损失，就让它删掉。

现实长文核材料和过程，虚构稿核人物目标、行动和变化。诗歌的意象和感受也要移动，但不强制完整散文句法或每段回答一个问题。

### 检查说话者

作者凭什么知道、为何在意，是否从材料里能看出来。没有亲历时，作者的取舍和判断也能形成声音，不必编“我见过”。

不要用增加称呼、粗口、错别字或固定自我修正制造口语。保留输入中本来就成立的语气。

## 第三层：语境复核与局部修改

| 候选问题 | 如何判断 | 正常例外 |
|---|---|---|
| 翻案或转折 | 是否虚构读者的误解，再通过推翻抬高下文 | 有材料支持的事实纠正、实际经历中的认识变化 |
| 黑话和抽象词 | 能否说清谁做什么、钱或时间落到哪里 | 实物、技术概念、人物说话和准确术语 |
| 名词化 | 改成动作能否更清楚 | 名词本来就是讨论对象 |
| 比喻 | 是否改变理解，是否有来源或属于人物视角 | 文学创造、实际物件、恰当的局部借喻 |
| 排比 | 是否只有相同意思排队，妨碍信息推进 | 用户要求的排比、诗歌、台词、修辞确实承担作用 |
| 短句与留白 | 是否反复把普通判断独立成段，像连续喊口号 | 社交短文、对白、诗歌或有实际停顿价值的句子 |
| 情绪解释 | 动作是否已传达相同感情 | 动作看不出的心理、必要权衡与神态仍应写 |

词表、规则编号、默认文体范围和检测模式统一在 [style-rules.json](style-rules.json)。本文件不给另一套重复禁词清单。

正常的“不是……而是……”可能在准确纠正事实，“不只……还……”可能是正常递进。不要见到字面就删除，也不要把正常句绕成更拗口的表达。

冒号、破折号和引号按实际功能使用，不要求清零。频繁用提示词给普通段落抬价时，从原意改写；用户明确要求不用时才作为本轮硬条件。

### 中文顺序与节奏

先让做事的人和动作出现，剩下的条件与背景顺着接。前句交出了人、物或结果，后句应有清楚照应。

复杂关系允许长句，已经落地的事情可以短句结束。不要为降低句长统计而加短口号，也不为了避免重复词而连换同义词。

## 第四层：虚构与结尾复核

虚构人物何时知道什么、为什么行动、前后怎样变化，必须自洽。动作后多余的情绪标签可以删，必要心理不能删空。

把最后两段分别拿掉试读。若内容已经结束，就停在结束处。不要额外总结全文、突然上升到时代或把每篇都变成号召。

首尾照应必须有事物作用或理解的变化，不能为了漂亮收束凭空造道具。

## 工具与最终交付

运行 [检查脚本](../scripts/check_writing.py) 后处理以下结果：

- `error`：脚本能确定的本轮长度或显式禁项失败，修复或诚实说明冲突。
- `review`：回到原意、材料和文体判断；成立可保留，不能只为消掉提醒而改。
- `info`：只作风格参考，用户未要求时不机械执行。

退出 0 不是事实或文风合格证明。最终仍需检查作者是否可信、哪里值得继续读、哪里多说了、任务是否完成。

只有实际朗读和计时过，才能说已朗读、实测时长。只有实际检索和核验过，才能写检索痕迹。

用户只要作品时不附检测报告。必要来源与关键篇幅冲突属于交付信息，不等于展示内部推理。
