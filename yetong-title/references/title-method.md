# 本地会员标题方法

标题的任务不是凑一个“爆款句型”，而是让该教练服务半径内的潜在会员快速判断：这篇是否回答了我正在考虑的问题。先有具体内容承诺，再选表达切口；没有对应正文或真实素材时，标题只能是待验证方向。

## 六种可选切口

这些是内容角度，不是可逐字填空的固定模板。一次只选择证据和正文确实支持的切口，不要求六种都使用。切口名称不同不代表标题有实质差异。

| 切口 | 适用条件 | 标题应让会员看见什么 | 不适用时的风险 |
| --- | --- | --- | --- |
| 当下顾虑 | 档案或本次材料中有具体咨询、疑问 | 她／他正在犹豫的那件事会得到回答 | 把教练想象的顾虑冒充会员原话 |
| 到店情境 | 服务区域、通勤、排课或生活时段真实相关 | 这篇与本地线下可执行的安排有关 | 只在前面加城市名，正文仍是泛泛科普 |
| 服务过程 | 有本人持续在做、可说明条件的动作 | 购买或上课后具体怎样被服务 | 把条件性处理写成无条件承诺 |
| 判断依据 | 正文能教会员自己核对一项选择标准 | 读后能多一个实用判断，而非只看广告 | 标题提出检查方法，正文却不给方法 |
| 本人选择 | 有获准公开的经历、取舍或明确立场 | 为什么这位教练这样做 | 把其他教练的经历或通用金句套成此人的话 |
| 合理澄清 | 有事实依据可解释一个常见误会 | 读者原来的担心哪里需要区分条件 | 为冲突而反对常识，滑向健康误导 |

## 候选筛选

对每个标题问五个问题，给出文字判断，不计算伪精确总分：

1. **对象**：本地潜在会员能否看出它与自己的到店、训练或购课情境相关？标题吸引来的是否主要是同行，而不是会员？
2. **承诺**：标题暗示的答案、数字或服务，正文能否在开头和主体中兑现？若还没写正文，标注待兑现内容。
3. **证据**：地名、本人故事、服务频率、效果和案例是否来自已确认且可公开的资料？不能以“听起来合理”替代依据。
4. **表达**：是否自然、清楚、好读，符合该教练已确认的说话习惯？没有语言样本时说明仍待本人校准。
5. **风险**：是否有医学因果、普遍效果保证、羞辱身材、夸张价格承诺，或可能识别会员的细节？

把其中最严重的缺口放在推荐理由前；不要因为标题更刺激，就压过本地相关性、真实性和会员信任。原标题若已有优点，保留它已明确的对象与问题，只改最影响理解的一处。

## 候选去重与数量边界

生成候选后，把每个标题还原成“谁会点开／期待得到什么”。两个标题若面向同一人、重复同一疑问且正文只会给出同一答案，就属于同一候选；只保留更清楚、更像本人说话的那个。不要把同义替换、问号改感叹号、硬加城市名或调换语序算作新角度。

若材料只够支撑一个清楚的标题，直接给这一个并说明原因，比凑满数量更有用。要扩展到更多标题，优先补会员真实问法、另一个可公开的服务环节或正文确会回答的不同问题；不能凭空补出资质、统计、承诺和案例。

## 与其他模块的交接

- 上游选题 Skill 交来的“工作标题”是角度标记，不等于正式发布标题。本模块接收其本地客群、具体问题、内容类型与证据链。
- 文案 Skill 可在草稿完成后调用本模块定稿标题；本模块不替文案 Skill 编正文来支撑标题。
- 内容体检 Skill 负责整篇内容的问题排序；用户只问标题好不好、要换什么标题时由本模块处理。若用户同时要整篇体检再改标题，先体检，再用确认后的正文承诺定标题。
