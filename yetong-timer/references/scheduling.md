# 原生调度与私有资料绑定

仅在用户要求创建定时热点选题时读取。本文件指导注册真实任务，不提供独立后台服务。只制作 Skill、展示指令或试跑不是创建授权。

## 注册前准备

读取当前上下文已确认的配置，只补问尚缺项：

| 配置 | 要确认的内容 |
| --- | --- |
| 人物来源 | 本人 `profile_id`、私有档案引用、激活状态及当前版本；不能只写“根据我的 DNA”而没有可访问来源 |
| 执行资料 | 未来环境可读取的 `yetong-timer` 及热点规则；优先绑定 `yetong-topic` 八大元素资源 |
| 时间 | 用户指定的执行时间、重复频率、时区；必要时起止日期。采用可识别时区标识，不从城市、IP推定 |
| 环境与结果 | 本地还是云端；本轮授权的原生任务及默认收件位置。另发微信、飞书群或客户消息须另有明确授权 |
| 历史 | 已可访问的同一任务近7天结果，或明确“未绑定历史”；历史不是创建硬门槛，不假称可读 |

若用户已说“每天”，频率直接沿用；已有时区、时间与档案引用不重复问。缺时间信息时可合并问：“希望什么频率、几点执行，按哪个时区？”根据缺项精简，不重做 DNA 访谈。长期任务无需强制问结束日期；用户指定阶段或到期时才写入。

## 检查未来运行环境

- 发现当前真实提供的原生定时工具、连接器或获准操作的调度界面，阅读其实际说明。不要从平台名称推测 API，更不能把别的产品函数当作本平台工具。
- 验证未来运行模式能访问本人档案、Skill 和联网能力，而不仅是当前聊天能读取。手机云端不能直接使用电脑本地路径；电脑安装 Skill 不等于云端已安装。
- 云端引用应来自用户已授权的私有上传、库／项目文件或连接器。不能为了方便把私人 DNA 放进 GitHub、公开网页或 Skill；需要向新的云服务上传私人档案时，先取得该传输授权，尽量只传本任务需要且获准的资料。
- 没有可持续引用时，明确“资料尚未绑定，未创建”；可由用户选择绑定私有文件。不要把当前聊天记忆、一次截图或模型自述记住了当成持久文件依据。
- 优先先试跑一次。试跑用真实检索，不把测试数据当当日热点；如果网络受限，明确展示常青降级，用户接受此限制后才按该环境注册。不能将另一平台或本地试跑当手机云端试跑。

## 固定执行提示词如何保存

原生任务要保存实际绑定的 Skill 引用、本人档案引用和身份、热点规则引用、时区及可用历史位置。调度频率保存在原生配置，运行提示词中不重复创建调度。任务名称建议“叶童每日热点选题｜本人称呼”，称呼来源于该用户，不全部命名为叶童本人。

以以下固定运行段落为基础，随后追加本次实际绑定信息；向宿主提交前填全真实引用，不提交示例路径或空模板：

```text
这是已注册定时任务的一次运行，不是创建请求。使用已绑定的 yetong-timer，重新读取绑定的本人 DNA 并核验 active、身份与逐条公开权限。只服务这位教练的本地潜在会员，允许相关泛曝光建立专业信任，不强行卖课，不教同行。
重新读取本任务热点规则，优先读取绑定的 yetong-topic 八大元素方法；未取得时按内嵌规则执行并如实标记。先查看当次可用抖音热榜，再查健身、减肥饮食和本人业务话题；跨行业热点必须连接真实工作场景。按24小时、必要时72小时窗口分别核对事件与发布时间，不估算指标、增长或排名，不把其他平台热度当抖音。
形成6—9个候选，只输出3个不同核心问题；按受众业务相关性、时效、传播潜力、内容增量、可拍性筛选，每题用1—2个真正应用的元素并标四大内容类型。能读近7天历史则按实际范围去重，读不到如实注明。缺热点以明确标记的常青备用题补足；无联网说明限制，未激活或读不到DNA则停止个性化，不能编造热点、经历、客户、成绩或观点。
按绑定热点规则的日报卡片格式返回日期、实际检索截止时间、数据／规则／历史状态，以及每题的具体问题、内容类型、关联热点、来源与时间及真实热度、元素应用、2—3句拍摄切入、对本人目标会员的价值及本人依据，最后给最先拍哪题的理由。只给选题和必要依据，不扩写正文、开头、脚本、分镜或封面，不发布，不联系客户，不创建或修改任何后台任务。
```

方法资源不能在未来环境读取、但宿主允许保存完整指令时，可将公开的热点规则内嵌到**私有任务配置**，保留版本和“按内嵌规则执行”状态；不得假称已安装、已调用 Skill。不得只存一句“照上次规则做”。人物档案仍要有可读的私有引用，不借内嵌方法绕过 active。

## 调用原生能力与验收

1. 只在本次明确要求创建、配置完整且资料可访问时调用原生工具。检查已知任务标识／当前用户同一任务，已有同源任务则先核对，不能反复说一句话就悄悄重复创建。用户明确要第二个任务才新建；调整现有任务需明确调整授权。
2. 使用宿主实际 schema，不在用户面前手写调度指令、编造 API 或用系统 cron 替代。Codex 若提供 `automation_update`，先发现并按其说明执行；默认使用当前聊天的定时任务，不因想按时运行就另建项目 cron，只有用户明确要求独立任务才用独立模式。保存清晰人类可读指令，不指定无必要的模型或项目。
3. 工具明确成功后，核对任务标识和原生列表／保存的配置。工具结果不明确或超时，先查询结果，不能盲目重试增加重复任务。没有可核对的成功证据写“创建结果未确认”，不承诺会自动运行。
4. 只有已取得可核对的任务标识、启用状态、执行时间／重复频率及时区，才能确认创建成功；缺任何一项时报告“创建结果未确认”并查原生任务列表，不重复创建。成功回复包含任务名称、标识、启用状态、执行时区、重复频率、平台返回或原生界面显示的下一次运行时间，以及实际运行环境。下一次时间不可取得时写“未取得，需在原生任务列表核对”，不凭计算装作平台返回。首次内容试跑通过仍需说明不等于已验证到点触发。
5. 没有原生工具／无法操作界面／权限不足／资料不可读时明确“未创建”及原因。交付准备好的固定运行指令与用户的实际配置，指导粘贴到宿主入口；这不是创建成功。可使用当前宿主帮助管理任务，不把本模块描述成支持任意定时服务。

## 平台核实范围（2026-10-07）

这些是接入依据，不是永久功能保证。执行时仍以当前账号、端、工具和实际试跑为准。

- **Codex／ChatGPT：** 官方允许 Skill 创建或更新任务。桌面本地文件任务需电脑开机、应用运行；网页任务需上传／连接的可用资料，不能读取电脑目录，也不保证每轮保留本地文件。优先将方法绑定为可用 Skill，档案用可访问私有引用。[官方定时任务说明](https://learn.chatgpt.com/docs/automations)
- **WorkBuddy 手机小程序：** 官方 Cloud 模式支持配置频率与时间、选择 Skills、对话创建和测试运行；云模式无需电脑开机。必须实际检查云端能选中本 Skill、资料引用可读；不能假定桌面自定义 Skill／私人文件自动同步。[官方自动化说明](https://www.workbuddy.cn/docs/workbuddymini/features/Auto)、[官方云端案例](https://www.workbuddy.cn/docs/workbuddymini/use-cases/Cases-Three)
- **豆包：** 官方桌面产品说明列出 Skills、浏览器与定时任务；工作任务须知区分本地／云电脑，并说明本地目录技能本身不上云。不能据此保证手机云端可一句话创建且持续读取自定义 Skill 和 DNA。发现实际原生入口或工具后再注册并试跑，不编造函数，不借用 TRAE／扣子的能力。[官方产品说明](https://apps.apple.com/cn/app/%E8%B1%86%E5%8C%85/id6683305962?mt=12)、[工作任务须知](https://www.doubao.com/legal/DoubaoAgentModeNotice)

运行时健康事实的检索与热点监测可能消耗宿主额度；有付费权限／额度或登录限制时如实说明，不绕过。只给可靠证据支持的承诺。
