# 本地内容五关体检规则

五关依次回答“谁会停下来、为什么可信、能否看懂、读完得到什么、接下来如何验证”。每关只根据已提供材料和当前教练的已激活人物档案判断；选题与成稿的证据标准不同。

| 关口 | 核查问题 | 常见最小修改 |
| --- | --- | --- |
| 1. 本地受众命中 | 内容是否指向该教练实际可服务区域内的一类潜在会员，以及她／他们眼下会问的具体问题？出现地名后是否仍和到店场景有关？ | 用档案中真实客群的一句顾虑替换宽泛话题；删除无法服务的地域承诺。 |
| 2. 事实与公开边界 | 经历、资质、场馆规则、服务频率、价格、训练结果是否有明确来源、适用条件和公开权限？会员案例能否被小范围识别？ | 把绝对话改成可证实的过程或个案；未获授权的数字、截图、身份线索先移除。 |
| 3. 第一眼识别 | 标题／封面／首段是否让目标会员看出“与我有关、这篇回答什么”；承诺是否与正文一致？未提供的素材不评分。 | 保留具体问题与真实场景，删掉悬空惊叹、空洞形容或正文无法兑现的钩子。 |
| 4. 阅读收获与本人表达 | 正文是否给出一条能理解或使用的判断依据／服务过程，有没有可证实的新认识；句子是否顺、信息是否重复；是否符合该教练真实说法和所选内容类型？ | 提前放回答，删重复，用确有依据的观察替换空泛结论，把套话替换为本人确实说过的表达或服务动作；没有语料则标为待本人校准。 |
| 5. 制作与验证 | 建议的照片、记录、动作、口播是否真实可取得且可公开；AI 能帮忙整理哪些已证实材料、哪些事实须教练本人补证；发布前能否用最小动作核验？ | 改用可拍的场馆／本人过程素材；列出需要查证的凭据及一项可完成的下一步，让 AI 只处理已提供的真实素材。 |

## 判断边界

- “通过”只指**当前已提供材料**未见该关的明显缺口，不等于平台审核通过或最终可发布。
- “需修改”须引用原句或说明具体缺失，给出一个最小动作；“缺材料”说明需用户提供什么，不编造标题、数据或图像。
- 选题阶段优先看本地对象、具体问题、可验证的本人素材和内容类型；标题、封面、全文节奏只在有对应材料时判断。
- 成稿阶段检查标题—开头—正文是否兑现同一问题，读者能否看见真实服务动作；不因篇幅长短本身判好坏。
- 判断“像本人”必须找到该教练的已确认语言样本或明确反馈；语言样本不足时只指出哪些句子像通用广告话，不宣称完成文风复刻。
- 不要求每篇都刻意反常识；只有档案或现实服务过程能支持时，才指出读者可能获得的认知更新。AI 可以辅助排序、压缩、生成表达备选，不能替教练提供不存在的客户证言、过程照片或训练结果。
- 发布前硬性待确认事项包括：可能识别会员的细节或图片授权；可量化服务承诺和价格条款；训练与营养建议的适用条件；可能被理解为普遍保证的效果数字。

## 推荐输出骨架

```text
结论：这篇目前最影响本地会员理解／信任的点是……（没有材料时说明范围）。
体检：
- 本地受众命中｜状态｜依据｜最小动作
- 事实与公开边界｜状态｜依据｜最小动作
- 第一眼识别｜状态｜依据｜最小动作
- 阅读收获与本人表达｜状态｜依据｜最小动作
- 制作与验证｜状态｜依据｜最小动作
优先改：1–3 项，按影响排序。
发布前确认：只列当前材料里确实存在、尚未核实的事项。
```

如果用户只要一句反馈，可压缩格式，但不得掩盖失实、隐私或效果保证等关键问题。
