# 第一次使用 YETONG

这份说明写给第一次接触 YETONG Skill、不会编程、也没有使用过命令行的健身教练。

## 它能帮你做什么

YETONG 是给**主要服务本地线下会员**的健身教练使用的一组 Agent 工作方法。目前已经能帮助你建立自己的人物 DNA，并围绕所在城市的会员顾虑，做小红书选题、写文案、拟标题、检查内容和设计封面。它不是自动获客软件，也不保证播放量、咨询量或训练效果；它会要求内容有本人依据，避免把别人的故事写成你的经历。

Skill 可以理解为交给 Agent 的一份“专门工作说明书”。普通聊天需要你一次次解释自己的业务和写作要求；安装并使用这组 Skill 后，Agent 会按相应流程判断该先了解你、找选题，还是处理已有稿件。你的私人档案应保存在你自己可访问的位置，不放进公开 Skill 包。

## 安装后，先说这一句话

**安装完成并不等于 Agent 会自动弹出欢迎消息。** 不同 Agent 的安装界面不同，Skill 本身不能在所有客户端监听“安装成功”事件。打开一个新对话，发送：

> 使用 `yetong`，展示当前实际已安装的 YETONG 全部技能，按“小红书内容创作、朋友圈营销、业绩管理”三类介绍每项能做什么、怎么触发；已开发但本机缺失的标“未安装”，尚未开发的标“规划中”。然后告诉我第一步该做什么。

如果 Agent 能读到 `yetong` 主入口及其他六个技能，它应列出目前七个技能，并把朋友圈营销、业绩管理说明为规划方向。只看见一份介绍文字、却无法读取或调用相应 Skill，不算整包可用；让 Agent 检查已安装目录和能力登记表，不要假装缺失的模块已经安装。

若你要安装的 GitHub 仓库版本已包含这七个短名，且所用 Agent 允许安装 GitHub Skill，也可以把安装和介绍合成一句话：

> 请从 `yetongzhu463-stack/yetong-fitness-xhs` 安装全部 YETONG Skill。安装后核对 `yetong`、`yetong-dna`、`yetong-topic`、`yetong-copy`、`yetong-review`、`yetong-title`、`yetong-cover` 都能读取，再立即使用 `yetong` 展示三大类和每项触发方式。若当前手机云端环境不能安装或不能保存，请直接说明，不要只展示文档就说安装成功。

这是一条给 Agent 的请求，不是所有平台都能执行的自动安装协议；若安装与调用分成两步，使用上面的“安装后”一句话即可。

## 第一次真正开始

先告诉 Agent：“我在〔城市／商圈〕做线下健身，主要服务〔哪类本地会员〕，请用 `yetong-dna` 帮我建立人物档案。”短访谈先收集足以开始内容创作的业务、客户问题和服务动作；成长故事可以以后按需补充。请亲自核对事实、可公开范围和表达习惯，并在确认后激活自己的 `person-dna.md`。

要做个性化选题或文案时，把**自己**的已激活档案路径交给 Agent。没有激活档案，或档案属于另一位教练时，不应生成声称“像你本人”的内容。你也可以先看[完整技能目录](SKILL_CATALOG.md)，直接说出自己现在的需求，由 `yetong` 匹配已可用的技能。

做封面时，先交给 `yetong-cover` 一个已定选题或草稿。它会区分“只生成画面的无字底图提示词”和“包含准确叠字要求的完整封面成图指令”；前者单独拿去生图，通常还不是完整封面。若当前 Agent 能生图、所需本人/场馆参考素材可用且有授权，给出完整指令后会问你回复“直接生成”还是“继续优化提示词”。没有生图能力或缺素材时，应说明缺口，不会凭文字虚构你的脸或门店。

目前公开包只提供本地线下会员的小红书内容工作流。朋友圈营销和业绩管理尚未交付可调用的 Skill；看到这两类介绍，不代表它们已经安装。
