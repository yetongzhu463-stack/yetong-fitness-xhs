# YETONG 技能目录

YETONG 规划为面向本地线下健身教练的三条服务线。**当前已交付小红书内容创作，以及朋友圈中的具体课程产品营销；业绩管理仍是规划中。** 本次发布修订 `0.9.1` 仍包含 10 个 Skill，每日热点选题归内容线，不是第四类。朋友圈仅覆盖课程营销策划与计划内文案，泛人设、日常运营尚未上线。主入口、人物 DNA 和技能更新是共用基础，不构成第四条业务线。Agent 展示本目录时，应以实际已安装且可读取的模块为准，不能把规划能力说成已上线，也不能把规划／未覆盖列为安装缺失。

## 一、小红书内容创作｜当前可用

叶童将一线服务会员与运营内容时形成的观察，整理为“先理解教练本人，再判断本地会员的问题，最后选择内容形式”的工作流程。据叶童提供的经验口径，这些方法来自约五年的实践，以及近 2,000 篇内容的创作与复盘。**当前公开 Skill 包收录的是提炼后的方法、判断规则与内容结构，不包含近 2,000 篇案例全文**；经验数字也不是流量或成交保证。每篇内容仍须用这位教练自己的城市、真实服务和有权公开的素材来完成。

共同入口与人物基础：

| Skill 短名 | 能做什么 | 对 Agent 这样说 |
| --- | --- | --- |
| `yetong` | 识别当前需求与材料状态，匹配已登记、已安装的专项技能；缺档案时引导建档。 | “我想吸引附近会员，但不知道先做什么。使用 `yetong` 帮我判断。” |
| `yetong-dna` | 六组问题一次展示，支持一段语音建立或更新本人场馆优势、主力客群痛点、身份资质、服务标准、高光案例、选择理由与公开权限档案。 | “使用 `yetong-dna`，先帮我建立人物档案，我用一段语音一起答。” |
| `yetong-update` | 检查官方版本或更新当前这一套安装；保留人物档案和其他技能，新增已登记模块随更新加入。 | “更新叶童技能。”或“检查叶童技能更新。” |

小红书专项能力：

| Skill 短名 | 能做什么 | 对 Agent 这样说 |
| --- | --- | --- |
| `yetong-topic` | 从已激活人物 DNA、本地会员顾虑和可证明的服务场景中生成或延展具体选题。 | “使用 `yetong-topic`，给我五个面向附近会员的选题。” |
| `yetong-timer` | 每日热点选题：根据本人 active DNA 与可核实热点，每次给 3 题；支持单次试跑、创建每日原生任务和已注册任务的实际运行。 | “根据我的DNA帮我进行定时任务选题。”或“每天定时给我3个热点选题。” |
| `yetong-copy` | 根据已选题和本人资料写单篇小红书笔记，或按同一事实边界修改现有稿。 | “这个选题我选好了。使用 `yetong-copy` 帮我写一篇。” |
| `yetong-title` | 为已确定的问题、选题或正文拟标题、比较角度、最小幅度修改原标题。 | “正文已定，使用 `yetong-title` 只改标题。” |
| `yetong-review` | 体检具体选题或草稿是否打中本地会员、是否可信、是否像本人，并指出优先修改处。 | “使用 `yetong-review` 检查这篇哪里需要改，先不要重写。” |
| `yetong-cover` | 执行叶童原版单题编号流程，以本人参考图制作 3:4 真人实拍封面提示词和排版清单；缺图1先等上传，完成后可继续优化或授权生成。 | “使用 `yetong-cover`，按叶童原版流程给这篇做封面，一次问我一个问题。” |

除建档外，以上个性化内容能力都要读取**当前教练本人已激活**的人物 DNA。主入口可以根据自然语言需求分流，不要求记住每个短名。已有的选题或草稿可直接交给对应模块，不必从头重复访谈。

每日热点也面向这位教练本地潜在会员，抖音等平台只作为热点来源；允许泛曝光建立专业信任，不强卖课，不教同行获客，也不自动扩写脚本、发布标题、封面或发布。普通“出5题”仍走本地选题；课程“朋友圈每天4条计划”走课程营销，不自动注册定时任务。单次热点试跑仍用 `yetong-timer`，每次固定 3 题。

定时创建绑定本人 active DNA、热点方法和当前环境已核实的原生调度；缺时间或时区只补问，不擅定 9 点或中国时区。先核对已有同类任务，后台执行环境还须可读取档案与方法。可核对的任务标识、启用状态、时间与时区才构成实际创建结果，Skill 制作或安装不等于任务已成功。豆包／WorkBuddy 的原生能力需在当前环境核实，本包不提供编造 API 或手机云端实测承诺。取消和其他调度管理可使用宿主原生任务列表，模块不是通用任意任务服务。

更新能力无需人物档案。首次建档默认一次展示六组问题，第一组先问真实服务城市，再让用户按自己的城市补充区县／商圈，不能把示例或其他人的城市当作用户地点。已激活旧档案继续有效；新资料只在当前内容相关且获相应公开授权时使用。

## 二、朋友圈营销｜课程产品营销当前可用

这一服务线把叶童提供的课程宣传方法提炼为可执行流程：先讲清产品是什么、解决什么问题，再展示选择理由与过程标准，用真实反馈和结果建立信任，最后以有依据的成交和复购证明需求。每天围绕同一个课程标签持续表达，但内容角度、素材和频率随教练的真实情况变化；重复不是机械复制同一句话，也不保证成交。

| Skill 短名 | 能做什么 | 对 Agent 这样说 |
| --- | --- | --- |
| `yetong-promo` | 从本人已激活 DNA 和独立课程资料卡出发，梳理本地目标人群、痛点、产品优势与证据，安排每日朋友圈计划，并推荐、续写或修改对应文案。 | “我有一门新课，使用 `yetong-promo` 帮我梳理卖给谁、怎么推广，再安排每天的朋友圈。”或“按已有课程营销计划写今天的朋友圈。” |

课程可由用户新构造；草案先做明确标记的内部策划，公开成稿须使用已确认真实可交付的内容。新课不因未写进 DNA 就要求重新访谈，只有身份、城市、能力或公开承诺实质冲突才回建档核对。文案结构对应客户咨询、客户反馈、转账截图、会员蜕变四类营销型写法，但不要求每门课凑齐素材；没有真实反馈、对比、收款或复购就不编造。原图片、示例品牌与完整例文不分发，会员素材逐项核对授权。

**本模块不覆盖泛朋友圈人设、日常生活内容、代发、业绩管理或全国线上招生。** 小红书仍由原模块处理，不能仅因文案都属于“营销型”就混用平台流程。

## 三、业绩管理｜规划中

这一服务线计划把叶童关于线下健身业务的管理思路，整理成可检查、可复盘的诊断流程。当教练遇到线索不足、体验转化、课程交付、续课或转介绍等问题时，未来的专项技能应先确认具体事实和数据，再拆解问题所在环节，给出优先级、下一步动作与验证方式。它的目标是帮助教练把模糊的“业绩不好”变成可执行的改进任务，而不是承诺增长，也不把叶童的个人经验当作适用于所有门店的定律。**目前尚未提供业绩管理专项 Skill，Agent 不应声称已经可以调用。**

## 展示原则

用户说“展示所有技能”“安装好了能做什么”或首次调用 `yetong` 时，默认中文按实际登记与文件哈希校验列出模块、触发示例及三条服务线的准确范围；课程朋友圈不代表泛朋友圈已上线，规划中的业绩管理不是缺文件，也不拼造调用名。只有已登记启用模块缺运行文件才是安装不完整。当前宿主发现／实际调用及跨会话持久另列证据，未知写未验证，不凭目录或本轮补装宣称永久可用。
